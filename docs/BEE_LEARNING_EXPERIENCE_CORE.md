# Bee Learning Experience Core

版本：0.1.0（開學可用版）

## 目的

本文件保存 Bee 老師的教學靈魂，作為所有 AI 平台、Skill、Agent 與教材輸出的共同核心。平台可以更換，教學哲學、教材美感與課程演化方式不得消失。

## 核心宣言

> 教材不是作品，而是活的系統。

> 教材的知識、結構與生成來源必須可修改；最終呈現可以是鎖定美感的圖片式成品。

> 老師不應把時間花在重做教材，而應把時間花在觀察學生。

> 好的教材，不是老師一個人完成的，而是老師觀察學生，再和 AI 一起持續進化出來的。

## 三項不可分割的品質

1. **Evolvable｜可演化**：能依學生反應快速增加、替換或重排。
2. **Beautiful｜有美感**：每次改版仍維持一致的世界觀、構圖與視覺品質。
3. **Teachable｜可教學**：所有圖片、角色、金句與互動都必須幫助理解。

## 課程設計層級

```text
Lesson Flow
→ Structure DNA
→ Layout DNA
→ Guided Narrative Layer
→ Meaningful Quote Layer
→ Theme DNA
→ Visual DNA
→ Rendered Outputs
```

- **Lesson Flow**：整堂課的學習節奏。
- **Structure DNA**：依文體與內容選擇全文導航和段落副架構。
- **Layout DNA**：每張頁面的教學功能與資訊排列。
- **Guided Narrative Layer**：引導者、課文角色、任務與轉場。
- **Meaningful Quote Layer**：理解錨點、策略句、課文主旨與啟發句。
- **Theme DNA**：魔法、科技、偵探、自然探險、水彩繪本等世界觀。
- **Visual DNA**：配色、插圖、角色、圖框、留白、字級與圖示系統。

## Bee 老師的教學方式

### 發現優於告知

所有知識盡量依循：

```text
看 → 猜 → 比較 → 發現 → 命名 → 應用
```

### 圖片是理解證據

- 圖片不是裝飾。
- 圖片必須呈現字義、句意、人物情緒、事件關係或操作流程。
- 字群教學以「偏旁意義＋情境圖片＋語詞＋語境」為核心。
- 成語插圖必須表現實際語意，不能只畫字面。

### 引導者陪學生走進課文

引導者不是吉祥物，而是全課敘事主持人，可負責：

- 開啟任務
- 提出核心問題
- 提供學習策略
- 與課文角色對話
- 章節轉場
- 課末統整

角色對話必須區分：

- `課文原句`：逐字取自教材。
- `情境對話`：依課文證據轉化，不得改變人物原意。

### 金句是理解支點

金句可以是：

- 課文原句
- Bee 老師理解句
- 閱讀或寫作策略句
- 課堂共創句
- 課末帶走的一句話

金句不得冒充名人語錄或作者原文。

## 中高年級字詞教學

一、二年級以識字、筆順、注音與書寫為主；三年級以上逐步轉向形近字字群、偏旁意義、字義辨析與語境運用。

中高年級字群流程：

```text
看共同部件
→ 比較偏旁
→ 用圖片理解字義
→ 配對語詞
→ 情境選字
→ 句子或短文運用
```

教材提供的形近字標示 `教材重點`；教師補充標示 `Bee老師補充`。

## 全文導航原則

全文結構圖不採單一固定心智圖。先判斷學生最需要理解的關係：

- 事件順序：故事流程或時間軸
- 人物改變：成長歷程
- 問題與解法：問題解決流程
- 多項資訊：分類樹或比較矩陣
- 寫景：感官導覽圖
- 童詩：意象地圖或情緒路徑
- 論說：主張、理由、證據、結論

每課可同時使用：

```text
Macro：全文主架構
＋
Micro：段落或語文知識副架構
```

## 多模態輸出

同一份 Lesson DNA 可生成：

- 圖片式教學簡報
- 可編輯 PPTX（選配）
- NotebookLM 圖文簡報來源與生成指令
- Podcast 課文導讀
- Podcast 語文知識
- Podcast 寫作教練
- 預習單
- 短文創作單
- 其他語文應用任務
- 平板活動與紙本替代

## 語音主持人原則

音訊主持腳本使用五種教學動作：

- `HOOK`：引起好奇
- `EXPLAIN`：整理概念
- `MODEL`：示範思考
- `PAUSE`：讓學生停下思考或口說
- `CHALLENGE`：提出任務

視覺主持與語音主持應共享同一角色 DNA、語氣與教學行為。

## 可演化來源與圖片式成品

### 可修改來源層

至少保存：

- LKB
- Lesson Flow
- Structure Profile
- Slide Script
- Visual Profile
- Guide Character Profile
- Quote Profile
- NotebookLM Source
- NotebookLM Generation Instructions
- Output Manifest

### 渲染成品層

可接受：

- 不可逐項編輯的圖片式簡報
- PDF
- 每頁獨立圖片
- NotebookLM 生成成品

需要修改時，回到來源層建立新版本，不在圖片上硬改。

## 自然語言修改

教師可用幾句話描述需求，例如：

> 第三段太難，增加三格圖解；形近字補充「喻、輸」；維持原本偵探風；Podcast 多一個生活例子。

Agent 必須先轉成標準 Change Request，保存修改原因、目標、操作、來源類型、視覺限制與受影響輸出，再執行更新。

## 現階段最小可用成果

開學前每課先完成：

1. 核准的教材知識與 LKB
2. 全課導航與分段教學流程
3. 圖片式簡報腳本
4. 引導者出場與對話規格
5. 必要金句
6. NotebookLM Source 與生成指令
7. 教師備註與答案
8. Output Manifest

預習單、短文創作單、Podcast、平板與其他延伸可依時間和需求追加，不阻擋先完成可上課的圖片式簡報。
