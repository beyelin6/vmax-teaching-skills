# Bee Quality Benchmark 1.0

> 目的：任何新版 V-MAX 產出，最低標準必須不低於 Bee 老師過去已完成、已認可的優秀成品。新版只能進化，不能退化。

## 基準作品

1. `Linguistic_Field_Guide`
2. `山椒魚語文探險`
3. `Taiwan's Glacial Salamander Quest`

這三份作品共同建立 V-MAX 的最低品質基線。

---

## 一、不可退步的核心品質

### 1. 世界觀一致性
- 同一課必須活在同一個視覺世界。
- 不可每頁像不同 AI、不同模板、不同教材。
- 章節、角色、色彩、材質、場景要有連續性。

### 2. 圖像必須承擔教學功能
- 圖片不是裝飾。
- 圖片必須幫助理解字義、句意、修辭、結構、情境或情緒。
- 字群、成語、句型、修辭優先採可比較、可推理、可記憶的視覺設計。

### 3. 角色必須活在課程裡
- 引導角色不是固定角落貼圖。
- 角色需依任務扮演觀察者、提問者、提示者、揭曉者、同行者、統整者。
- 角色台詞不得重複套版。

### 4. 每頁要有清楚的理解任務
每一頁必須能回答：
> 學生為什麼現在要看到這一頁？

若拿掉一頁不影響理解，就應考慮刪除或合併。

### 5. 學生語言必須自然
- 避免教案式摘要直接放到學生畫面。
- 優先使用可觀察、可比較、可猜測、可回答的語言。
- 教師分析放 Speaker Notes，不塞進學生畫面。

### 6. 語文知識不得降級
若舊版已有：
- 正確字音
- 部首
- 語詞
- 字形比較
- 記憶線索
- 語境

新版不可退化成：
- `注音由教師確認`
- `造詞`
- 空泛摘要
- 無教學功能的配圖

### 7. 整課必須有節奏
- 不可用固定三頁模板重複所有段落。
- 依文體、內容與學習目標決定節奏。
- 需有感受、發現、深化、比較、統整、應用或創作等不同學習動作。

### 8. 視覺結構要回應文本結構
- 寫景文：遠景／中景／近景、移步換景、時間推移等要被視覺化。
- 童詩：意象、節奏、重複、留白與聯想要被看見。
- 故事文：事件、轉折、停格、揭曉要有分鏡節奏。
- 說明文：分類、因果、比較、總分結構要有對應圖式。

## 二、三份基準作品值得保留的 DNA

### Linguistic Field Guide
- 字群同框比較。
- 具體圖像對應部件與字義。
- 多音字使用不同場景區分語意。
- 成語用高記憶度完整場景，而非只有定義與例句。
- 語文知識視覺化程度高。

### 山椒魚語文探險
- 語文活動仍留在同一探險世界觀。
- 形近字、助詞、句型、閱讀策略都有不同視覺隱喻。
- 角色參與學習，而不是站在旁邊解說。
- 語文規則被轉譯成可理解的畫面。

### Taiwan's Glacial Salamander Quest
- 全文結構以探險地圖呈現。
- 不同段落有不同鏡頭與氛圍。
- 修辭、句型、閱讀理解嵌在故事場景中。
- 情緒、色彩與場景跟內容推進一起變化。
- 整課有明確旅程感。

## 三、V-MAX 2.0 必須新增的進化層

在不低於以上基準的前提下，新增：

1. `Director Engine`：先決定整課觀看與理解節奏。
2. `Visual Grammar`：把文本結構轉成視覺語法。
3. `Visual Sequence`：需要過程時用連續畫面、漫畫、分鏡或時間序列。
4. `Knowledge Network`：字、音、義、部件、語詞、成語、句型、修辭建立關聯，不做孤立卡片。
5. `Comparison Scene`：形近字、字群、概念比較優先同框。
6. `Teacher Sovereignty`：AI 可推薦，不擅自改變教師教學意圖。
7. `Regression Gate`：新版若失去舊版已有的優點，直接判定不通過。

---

## 四、Regression Gate

任何新產出進 Renderer 前，至少檢查：

- [ ] 世界觀是否比基準作品一致或更好？
- [ ] 圖片是否真的幫助理解？
- [ ] 角色是否有功能，而非裝飾？
- [ ] 學生文字是否比舊版更自然？
- [ ] 語文知識是否完整，沒有降級成半成品？
- [ ] 是否避免機械重複頁型？
- [ ] 是否有清楚的整課節奏？
- [ ] 是否有至少一個可形成強烈畫面記憶的設計？
- [ ] 若與舊成品並排，新版是否至少在「教學清楚度、畫面記憶、節奏、角色自然度」四項中有三項更好？

若未通過，不進入正式簡報渲染。

## 五、第一課 V2 暫行原則

第一課《水陸小高手》舊 47 頁版降級為「內容素材庫」，不作為版型骨架。

重構順序：

`課文 DNA → 整課 Director Map → 學習節奏 → 語文知識配置 → 角色出場 → 視覺語法 → 代表頁文字稿 → 教師確認 → Renderer`

在整課骨架確認前，不生成正式簡報。
