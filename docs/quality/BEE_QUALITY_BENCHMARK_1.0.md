# Bee Quality Benchmark 1.1

> 目的：任何新版 V-MAX 產出，最低標準必須不低於 Bee 老師過去已完成、已認可的優秀成品。新版只能進化，不能退化。

## 基準作品

1. `Linguistic_Field_Guide`
2. `山椒魚語文探險`
3. `Taiwan's Glacial Salamander Quest`

這三份作品共同建立 V-MAX 的最低品質基線。

---

## 一、不可退步的核心品質

### 1. 世界觀一致性
- 同一課必須活在同一個視覺世界。
- 不可每頁像不同 AI、不同模板、不同教材。
- 章節、角色、色彩、材質、場景要有連續性。

### 2. 圖像必須承擔教學功能
- 圖片不是裝飾。
- 圖片必須幫助理解字義、句意、修辭、結構、情境或情緒。
- 字群、成語、句型、修辭優先採可比較、可推理、可記憶的視覺設計。

### 3. 角色必須活在課程裡
- 引導角色不是固定角落貼圖。
- 角色只在能改變注意、理解、策略、情緒或轉場時出現。
- 角色台詞不得重複套版。
- 若拿掉角色不影響理解，優先拿掉。

### 4. 每頁要有清楚的理解任務
每一頁必須能回答：
> 學生為什麼現在要看到這一頁？

若拿掉一頁不影響理解，就應考慮刪除或合併。

### 5. 學生語言必須自然
- 避免教案式摘要直接放到學生畫面。
- 優先使用可觀察、可比較、可猜測、可回答的語言。
- 教師分析放 Speaker Notes，不塞進學生畫面。

### 6. 語文知識不得降級
若舊版已有：
- 正確字音
- 部首
- 語詞
- 字形比較
- 記憶線索
- 語境

新版不可退化成：
- `注音由教師確認`
- `造詞`
- 空泛摘要
- 無教學功能的配圖

### 7. 整課必須有節奏
- 不可用固定三頁模板重複所有段落。
- 依自然段／意義段、文體、內容與學習目標決定節奏。
- 需有感受、發現、深化、比較、統整、應用或創作等不同學習動作。

### 8. 視覺結構要回應文本結構
- 寫景文：遠景／中景／近景、移步換景、時間推移等要被視覺化。
- 童詩：意象、節奏、重複、留白與聯想要被看見。
- 故事文：事件、轉折、停格、揭曉要有分鏡節奏。
- 說明文：分類、因果、比較、總分結構要有對應圖式。

### 9. 圖文整合品質不得退化
- 不為了追求全部可編輯，將圖片與文字拆成僵硬的左右區塊。
- 允許使用 Image-first Hybrid Renderer：先完成整張投影片的圖文構圖，再決定哪些文字需轉為 Native Text Overlay。
- Native Text 若存在，必須像原本就在畫面裡，而不是後來貼上去。
- 若將文字原生化會明顯破壞構圖與閱讀節奏，可保留圖片式文字，但需通過文字正確性檢查。

## 二、三份基準作品值得保留的 DNA

### Linguistic Field Guide
- 字群同框比較。
- 具體圖像對應部件與字義。
- 多音字使用不同場景區分語意。
- 成語用高記憶度完整場景，而非只有定義與例句。
- 語文知識視覺化程度高。

### 山椒魚語文探險
- 語文活動仍留在同一探險世界觀。
- 形近字、助詞、句型、閱讀策略都有不同視覺隱喻。
- 角色參與學習，而不是站在旁邊解說。
- 語文規則被轉譯成可理解的畫面。

### Taiwan's Glacial Salamander Quest
- 全文結構以探險地圖呈現。
- 不同段落有不同鏡頭與氛圍。
- 修辭、句型、閱讀理解嵌在故事場景中。
- 情緒、色彩與場景跟內容推進一起變化。
- 整課有明確旅程感。

## 三、V-MAX 2.0 必須新增的進化層

在不低於以上基準的前提下，新增：

1. `Director Engine`：先決定整課觀看與理解節奏。
2. `Visual Grammar`：把文本結構轉成視覺語法。
3. `Visual Sequence`：需要過程時用連續畫面、漫畫、分鏡或時間序列。
4. `Knowledge Network`：字、音、義、部件、語詞、成語、句型、修辭建立關聯，不做孤立卡片。
5. `Comparison Scene`：形近字、字群、概念比較優先同框。
6. `Teacher Sovereignty`：AI 可推薦，不擅自改變教師教學意圖。
7. `Image-first Hybrid Renderer`：優先保留整體圖文構圖美感，必要時再做原生文字覆疊。
8. `Regression Gate`：新版若失去舊版已有的優點，直接判定不通過。

## 四、Renderer Text Accuracy Policy｜渲染文字正確性政策

### A. 必須零錯誤（Zero-Tolerance）
以下內容若出錯會直接影響教學正確性，必須校正後才能交付：

- 課文原句／原文引用
- 生字字形
- 注音與聲調
- 多音字讀音與語境
- 形近字比較中的正式字形
- 成語本體
- 正式成語定義
- 題幹、選項與答案關鍵字
- 學生需要抄寫／朗讀／辨識的文字

若圖片式渲染無法穩定正確，該區域必須改用 Native Text Overlay、程式化文字或重新渲染。

### B. 可接受微小誤差（Low-Risk Tolerance）
若不影響學生學習與作答，可允許極少數非核心裝飾文字出現小瑕疵，例如：

- 場景中的次要招牌
- 背景手帳小字
- 不承擔教學功能的裝飾標籤
- 不需朗讀、抄寫、辨識的微型環境文字

但必須同時符合：

1. 不會被學生誤認為正式教材文字。
2. 不會改變學習任務或答案。
3. 不會大量重複出現。
4. 不可因「允許小錯」而放棄整體文字校對。

### C. Hybrid Escalation Rule｜何時升級成原生文字
符合任一情況，即優先使用 Native Text Overlay：

- 同一區塊出現 2 個以上核心文字錯誤。
- 同一頁核心文字重新渲染 2 次仍不穩定。
- 注音、字形、成語本體或題目需要精準對齊。
- 文字未來高機率需要教師修改。
- 錯誤可能造成學生學習誤解。

### D. 不接受的退化
- 不得因為文字正確性要求，就把每頁改成「背景圖 + 四方文字框」的傳統拼貼。
- 不得把所有圖片縮小後在旁邊排文字，只為了可編輯。
- 不得要求教師在交付後自行搬字、對齊或重做版面。

核心原則：

> 少數低風險裝飾字的微小瑕疵，可以換取整體圖文構圖的完整；但所有真正承擔教學功能的文字，都必須正確。

## 五、Regression Gate

任何新產出進正式交付前，至少檢查：

- [ ] 世界觀是否比基準作品一致或更好？
- [ ] 圖片是否真的幫助理解？
- [ ] 角色是否有功能，而非裝飾？
- [ ] 學生文字是否比舊版更自然？
- [ ] 語文知識是否完整，沒有降級成半成品？
- [ ] 是否避免機械重複頁型？
- [ ] 是否有清楚的整課節奏？
- [ ] 是否有至少一個可形成強烈畫面記憶的設計？
- [ ] 核心教學文字是否零錯誤？
- [ ] Native Text Overlay 是否真的融入畫面，而不是後貼？
- [ ] 是否避免把整套簡報退化成人工拼貼感？
- [ ] 若與舊成品並排，新版是否至少在「教學清楚度、畫面記憶、節奏、角色自然度」四項中有三項更好？

若未通過，不進入正式交付。

## 六、第一課 V2 暫行原則

第一課《水陸小高手》舊 47 頁版降級為「內容素材庫」，不作為版型骨架。

重構順序：

`課文 DNA → 整課 Director Map → 段落 Acts → 學習節奏 → 語詞／句型／修辭配置 → Knowledge Lab 教師篩選 → 角色出場 → Visual Grammar → 代表頁 → Quality Gate → Renderer`

在整課骨架與代表頁品質確認前，不生成完整正式簡報。
