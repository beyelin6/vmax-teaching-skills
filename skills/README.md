5. `presentation-engine`
6. `vmax-image-renderer`
7. `vqs-quality-validator`
8. `lesson-package-delivery`

每個技能至少包含 `SKILL.md`，並可依需要加入 `references/`、`templates/` 與 `scripts/`。
