# 預習單規格

版本：1.2

## 定位

本檔只定義**預習單特有**的視覺、列印安全與雙版本規則。A4 / PDF 共通的壓縮 profile、size optimization、PDF 重渲染 preflight、`PDF_OVERCOMPRESSED` 與一般 PDF 品質判斷，不在本檔重複定義，一律遵守：

- `core/export/infographic-pdf-output-contract.md`
- `core/renderer/image-first-hybrid-renderer.md`

若本檔與 Core Contract 發生衝突，以 Core Contract 為權威；本檔只能增加預習單特有 safeguard，不得另建第二套 canonical PDF 規格。

## 固定輸出

- A4 橫式 PNG：3508 × 2480。
- 正式列印基準固定為 **300 dpi**；不得為縮小檔案而降低 A4 預習單的列印 DPI。
- 純白底，可直接列印。
- 一課一張。
- 四年級閱讀尺寸；不得為塞內容而縮字或縮答案線。
- 學生可見區不顯示角色名稱、作者、答案、紅色訂正符號或版權字樣。

## 列印安全邊界｜預習單特有硬規格

- 畫布正確不等於可安全列印；每張成品都要量測「實際非白內容」到四邊的距離。
- 四邊最低安全白邊為 **4.5 mm**；3508 × 2480、300 dpi 時約為 **53 px**。角色、框線、裝飾、題目與答案線都算實際內容。
- 任一側低於安全白邊時，將**整頁等比例內縮＋置中補白**，以實測結果為準。
- 禁止只改 PNG 畫布大小、直接拉伸、裁切頁緣、局部擠壓或只移動最外側角色來假性通過。
- PNG 輸出後必須完整解碼；若 truncated / Read Exception / 結尾資料不完整，須由確認來源重新編碼。
- 合併 PDF 必須維持 A4 橫式頁面盒；替換頁面後重新渲染對應頁，檢查四邊留白、文字清晰度與截邊。

### PDF 安全瘦身

預習單只額外鎖定兩件事：

1. **正式 A4 列印版維持 300 dpi**。
2. **4.5 mm 實際非白內容安全白邊在壓縮後仍需 PASS**。

其他壓縮策略、圖片處理、output profile、100% / 200% 檢查與 `PDF_SIZE_OPTIMIZED / PDF_OVERCOMPRESSED` 判定，直接引用 `core/export/infographic-pdf-output-contract.md`，不得在本檔維護另一組 JPEG 品質值或第二套 profile 名稱。

## 雙版本設計系統

兩個版本共用完全相同的教學內容、白底、尺寸、角色一致性、書寫空間與校字標準；只改變框線、邊界、裝飾節奏和畫面組織。

### A｜清楚框線版

- 以清楚、穩定、可快速辨識的功能區為主。
- 每頁可使用 2–4 個主要框區，搭配少量細緻彩色外框；同類題目維持一致造型。
- 不要求每課都使用筆記本框線或左側裝訂圈；可依課文主題改用圓角框、局部頁角、簡單標籤或開放式分隔線。
- 形近字以緊湊的同組小卡或雙欄為優先，避免占滿半頁。
- 整體可活潑，但不可像 Word 表格、制式 UI 卡片或六個同尺寸方框。
- 視覺基準：`assets/lesson1-approved-reference.png`。

### B｜自由手繪版

- 每課只選 **1–3 種**框線或邊界語言混搭；這是硬性上限。
- 可選語言包括：局部框、粗細手繪線、紙膠帶、筆刷色塊、括弧、路徑輪廓、撕紙邊、主題軌跡線。
- 同類任務使用同一種邊界語言；變化主要發生在不同課次之間，不是同頁每個小卡都不同。
- 保留足夠留白與清楚閱讀順序，禁止碎框過多、裝飾散落、線條互相競爭。
- 框線可以不封閉，但題目歸屬和答案區界線必須一眼可辨。
- 視覺基準：`assets/lesson2-freehand-approved-reference.png`；第二課的整體節奏是優先參考，不照搬其課次主題圖示。

### 版本不可混淆

- A 版不得因局部手繪裝飾而被改名為 B 版。
- B 版不得退回所有區塊都是相同細框的 A 版語言。
- 同一份 PDF 只收錄同一版本。
- 若使用者要求「另做一版」，保留原版並建立另一模式的新檔。

## 內容優先順序

Renderer 不自行決定內容，只依 `PRESTUDY_WORKSHEET_SOURCE` 的已核准內容排版。若空間不足，依內容層已提供的 priority / optional 標記處理；不得自行改寫題目。

預習單常見內容優先順序可供版面配置參考：
1. 課文基本辨識。
2. 特殊句型。
3. 已確認的形近字與多音字。
4. 核心文意題。
5. 已標記 optional 的延伸觀察或 Bonus。

## 形近字

- 同組字放在同一視覺區。
- 兩字組可左右並列；三字組可三欄或同列。
- 每字格式需提供：`字（　　　）詞：＿＿＿＿＿＿`。
- 括號須能寫完整注音；造詞線須能寫二至四字。
- 不加入「本課／比較字」徽章，不標色拆部件，不使用大量紅色。

## AI 插畫與文字

- 可採整頁圖文同步生成，但**文字真值只能來自已核准來源**。
- 逐字校對與修復 fallback 依 `core/renderer/image-first-hybrid-renderer.md`。
- 若局部修復仍無法驗證文字，回退 verified/native-text 合成；不得無限重生整頁或接受錯字。
- 每課依課文主題與已確認設定選用角色，不固定套用 Bee 老師或某位學生。
- 若該課已有專屬角色，優先使用專屬角色；必要角色資料缺失時只阻塞該課。
- 學生版只呈現人物圖像，不直接顯示角色名稱。
- 標題不用固定長條框。
- 區塊可有不規則線條、貼紙、頁邊進場與局部重疊，但不可犧牲可讀性。
- 大型插圖最多形成兩個主要角色焦點；移除無必要的第三焦點。
- 主題圖示應靠近相關任務；禁止無關或結構錯誤物件。
- 插圖是畫龍點睛：少量、小型、靠近相關內容，不因框線自由而增加插圖數量。

## Approved Reference 使用規則

兩張 approved reference 只作**視覺語言基準**，不把參考課的題目、角色、裝飾主題或版面比例硬複製到其他課。

> Core PDF Contract 管共通輸出品質；Worksheet Spec 只管預習單特有的 A/B 視覺與列印安全。
