# Bee 老師教材字型系統｜V-MAX

版本：1.2.1

## 目的

建立 Bee 老師教材的固定繁體中文字型選用邏輯，讓簡報、PNG、PDF、學習單、親師手冊與其他 image-first 教材在不同工作區與不同 renderer 中，都能維持：

- 繁中字形正確
- 注音安全
- 國小中年級清楚易讀
- 視覺有設計感但不花俏
- 同一頁字型數量受控
- 缺字時有明確 fallback，不由系統任意代換

本規範只定義「功能角色」，實際使用前仍必須通過 `scripts/check_fonts.py`。

---

## 核心字型角色

### 1. 課文正文 `body_serif`

首選：Source Han Serif TW（思源宋體 TW）

Fallback：Source Han Sans TW

用途：
- 課文原文
- 閱讀短文
- 故事段落
- 人物傳記

規則：
- 長文優先宋體，提升段落閱讀感。
- 若頁面本身資訊層級較多、字數少，可改用思源黑體。
- 不使用粉圓或手寫體排長文。

### 2. 一般正文 `body_sans`

首選：Source Han Sans TW（思源黑體 TW）

Fallback：Iansui

用途：
- 詞語解釋
- 教學重點
- 小標說明
- 規則文字
- 教師文件一般內容

規則：
- 這是 Bee 老師系統的主要安全正文。
- 所有大量學生可見文字若無特殊理由，優先使用本角色。

### 3. 國字與生字 `character_learning`

首選：Iansui（芫荽）

Fallback：Source Han Sans TW

用途：
- 生字大字
- 形近字比較
- 部件辨識
- 國字教學

規則：
- 每課必須把該課目標國字加入 preflight 的 `--extra-text`。
- 若芫荽缺字，該字必須 fallback，不可硬輸出。
- 不使用手寫體、藝術字作生字教學。

### 4. 活動標題 `rounded_title`

首選：jf open 粉圓

Fallback：Source Han Sans TW

用途：
- 活動標題
- 任務卡
- 對話框
- 漫畫短句
- 低中年級友善標籤

規則：
- 一頁只作為標題或短句角色。
- 不排長篇正文。
- 建議搭配思源黑體正文。

### 5. 注音安全 `bopomofo_safe`

首選：已實測通過的 Iansui 系列注音字型

Fallback：jf open 粉圓 → Source Han Sans TW

用途：
- 大字＋橫式注音
- 注音練習
- 語詞注音

規則：
- 只要頁面有注音，`check_fonts.py` 必須帶 `--require-bopomofo`。
- 注音不可只看 cmap；代表頁需人工目視檢查聲調位置、基線、間距。
- 成語頁若教材規則禁止注音，不得因字型系統自行加注音。

### 6. 手寫裝飾 `handwriting_accent`

首選：待核准之合法手寫字型

Fallback：Iansui → Source Han Sans TW

用途：
- Bee 老師便利貼
- 角色手寫感短句
- 小提醒
- 情緒性裝飾標註

規則：
- 不可承載核心答案、長篇正文、生字教學。
- 單頁建議不超過 1–2 處。
- 任何新手寫字型都要先完成來源與授權核對。

## 版面與字型搭配規則

1. 同一頁主要字族原則不超過 2 套；注音專用字型不計入。
2. 標題與正文應有明顯層級，但不可為了「可愛」犧牲清晰度。
3. 中年級學生可見正文以大字、適度行距為優先；字型替換後需重新檢查換行。
4. 16:9 image-first 教材以 2560×1440 為標準 QA 畫布。
5. 文字不可直接燒進生成式插圖；繁體中文正式文字由可控文字渲染層負責。
6. 若 fallback 導致字寬或行高差異，必須重新做版面 QA，不可沿用舊框硬塞。

## Preflight 最低要求

每個實際使用的字型角色分別檢查；以下以生字角色為例。`skills/...` 為 repository 路徑，本機安裝時換成實際 Skill 目錄：

```bash
python skills/traditional-chinese-font-safety/scripts/check_fonts.py \
  --role character_learning \
  --font-dir assets/fonts \
  --extra-text "<本課所有目標國字與關鍵詞>" \
  --require-bopomofo \
  --report working/font-preflight-report.json
```

若本批次完全沒有注音，可移除 `--require-bopomofo`。

代表頁與最終成品需目視確認：
- 繁中字形
- 注音位置
- 標點
- 字級
- 行距
- 換行
- 不遮圖
- 無方框/缺字
- 字型 fallback 未造成版面崩壞

## 決策原則

當美感與教學正確性衝突時，順序固定為：

1. 字形正確
2. 清楚易讀
3. 注音正確
4. 版面穩定
5. 風格一致
6. 裝飾美感

不得反過來。
