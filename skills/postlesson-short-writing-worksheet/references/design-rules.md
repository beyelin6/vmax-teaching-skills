# 課後短文內容決策細則

> 本檔包含 Bee 老師目前四上系列的八詞預設與第 1～6 課核准案例。其他年級、學期或教師設定先讀 Output Profile；案例只供判斷方法參考，不是永久詞庫或跨年級硬規格。

## 1. 設計判斷順序

固定依下列順序工作：

1. 這一課要讓孩子學會的閱讀／寫作技能是什麼？
2. 哪個短文任務能讓孩子真正使用這項技能？
3. 課文的哪個句型、修辭或結構能成為操作鷹架？
4. 依 Output Profile 的目標數量，哪些課文語詞或生字相關詞語最容易自然進入這篇文章？Bee 老師目前四上預設為八個。
5. 學生需要哪些最少但足夠的提示才能開始寫？

若先選了題目才找教材內容，應退回第1步重做。

## 2. 八個語詞評分

對每個候選詞評估四項，每項0～2分：

| 指標 | 0分 | 1分 | 2分 |
|---|---|---|---|
| 教材關聯 | 無明確來源 | 延伸相關 | 課文核心、生字相關或重要語句 |
| 入文適合性 | 幾乎不能使用 | 需特定情境 | 可自然寫入本次短文 |
| 年級適切 | 太難或太專業 | 需較多解釋 | 四年級可理解並嘗試使用 |
| 功能價值 | 與其他詞重複 | 提供少量變化 | 能補動作、畫面、感受、轉折或主題 |

優先選總分7～8分。六分以下若要保留，必須有明確教學理由。

### 排除例

- 人物傳記中的「醫療、女學堂」雖重要，卻不一定適合「感謝一個人」短文。
- 登山課文中的「低氧訓練、世界七頂峰」不適合寫抽象生活目標。
- 只適合填文意題的名詞，不因為出現在課文就自動列入。

## 3. 句型、修辭與技能的選擇

### 句型

- 只放該課實際出現或語文活動指定的句型。
- 每張二至四個選項足夠。
- 標示「選一個就好」，不要變成機械套句。

### 修辭

- 譬喻：要求找出共同特徵，避免只挑漂亮意象。
- 擬人：先找物件動作，再轉為人的動作或情緒。
- 感官摹寫：選一至兩種最有力量的感官，不強迫五感齊全。
- 類疊／節奏：安排重複、交換或聲音，不只標注修辭名稱。

### 結構技能

- 倒敘：先呈現結果或精彩時刻，再回到起因。
- 以事寫人：用動作、話語、選擇證明特質。
- 成長歷程：目標 → 困難 → 行動 → 改變／收穫。
- 象徵：允許具體與抽象題材，例如「高峰」可代表技能、習慣、害怕或心態。

## 4. 困難題材轉譯

當課文的原始體驗對多數學生而言遙遠、危險、昂貴、專業、少見或難以親身完成，或題目大到學生難以下筆時，不把「複製原課文情境」當成寫作條件。依下列順序轉譯：

1. **抽取核心**：辨認真正要學的情感、概念與寫作技能，例如堅持、突破、關懷、觀察或面對挫折。
2. **判斷距離**：確認學生是否有足夠生活經驗、背景知識與安全條件可以書寫原情境。
3. **展開雙軌**：同時提供具體生活事件與抽象目標，讓學生選擇最有感的方向。
4. **縮小範圍**：把宏大主題縮成一個可說清楚的小目標、一次困難、一段行動或一個改變。
5. **保留技能**：情境可以改，該課句型、修辭、結構與核心概念仍須保留。

### 具體與抽象雙軌

- **具體體驗**：學騎腳踏車、游泳、比賽、上臺、完成作品、練習樂器、解開難題。
- **抽象目標**：克服害怕、養成習慣、控制脾氣、建立自信、學會合作、持續努力。

題目提示避免問「你是否也完成過和作者一樣的壯舉？」；改問「你曾遇過哪一件對自己而言不容易的事？」讓難度由學生自己的經驗決定。

第六課的「高峰」是此規則的案例：「高峰」可保留為真正的登山或具體挑戰，也可象徵技能、習慣、恐懼、心態或個人目標；不限定真正爬山。

## 5. 學習單品質檢核

內容版：

- [ ] 八個詞均可追溯且適合本次文章。
- [ ] 句型／修辭來自該課，不是泛用句型。
- [ ] 題目能讓學生展現該課目標。
- [ ] 若原課文體驗難以完成，題目已轉譯為學生可經驗的具體事件或抽象目標。
- [ ] 鷹架幫助思考，不代替學生寫答案。
- [ ] 自我檢核只評量本課真正要學的能力。

視覺版：

- [ ] 人物和該課預習單一致。
- [ ] 人物、插圖不壓縮書寫區。
- [ ] 八個詞清楚可讀，沒有錯字或簡體字。
- [ ] 學生可見區沒有英文、答案、角色名稱及版權。
- [ ] 150～200字書寫區是頁面最大區域。
- [ ] 四年級散文書寫線約十至十二條，行距至少達到已確認第二課、六課的舒適程度，不以密集線條表示字數。
- [ ] 童詩的線條依詩節分組，預設三節、每節三至四行，節間留有一眼可辨的段距。
- [ ] 正式輸出前已和核准基準頁並排檢查；若過密，先減少線數，再考慮其他版面調整。

歸檔版：

- [ ] 課後短文有獨立資料夾，不與預習單或其他教材混放。
- [ ] 單課 PNG 與合併 PDF 位於可辨識的年級、學期層級下。
- [ ] 同名更新與新增版本已依模式判斷，且上傳後已回讀驗證。

## 6. 四上第1～6課確認案例

| 課次 | 遷移目標 | 句型／修辭／結構 | 八個可入文語詞 |
|---|---|---|---|
| 第1課〈水陸小高手〉 | 把運動動作轉化成有畫面、有節奏的童詩 | 譬喻、聯想、類疊與節奏 | 晶亮、一串串、無比、遨遊、陀螺、跳躍、煩惱、多采多姿 |
| 第2課〈放學後〉 | 聚焦一個放學小場景，用感官與細節寫幸福感受 | 感官摹寫；不管……還是…… | 不約而同、香氣撲鼻、一掃而空、精神食糧、爭吵不休、奮勇爭先、不落人後、依依不捨 |
| 第3課〈我的籃球夢〉 | 寫出目標、挫折、練習與進步的心情變化 | 倒敘、擬人、譬喻；只要……就…… | 有朝一日、風雲人物、遙不可及、熟能生巧、此起彼落、平分秋色、喧鬧、優美的弧線 |
| 第4課〈永遠的馬偕〉 | 用具體行動表現人物特質 | 當……就……；以事寫人 | 下定決心、奉獻、翻山越嶺、紛紛、求助、披星戴月、救助、濃濃的情感 |
| 第5課〈假如給我三天光明〉 | 仔細觀察平常事物，寫出感官細節與珍惜 | 如果……一定……；多感官描寫 | 寧靜、觸覺、蓓蕾、綻放、舒適、五彩繽紛、姿態萬千、視而不見 |
| 第6課〈攀登生命的高峰〉 | 選一項對自己而言不容易的體驗或目標，把「高峰」作為具體挑戰或抽象象徵，寫出困難、行動與信念 | 無論……始終……；象徵與譬喻 | 千變萬化、不知不覺、磨練、谷底、不知所措、挑戰、排除重重難關、繼續前進 |

這張表是已確認案例，不是永久詞庫。來源教材、課次或使用者指示改變時，重新依評分規則篩選。
