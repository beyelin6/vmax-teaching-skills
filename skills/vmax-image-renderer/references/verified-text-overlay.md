# Verified Text Overlay

圖片式簡報的正式合成模式：`VERIFIED_RASTER_TEXT_COMPONENTS`

## 何時必須使用

課文原句、生字、注音、語詞、成語定義、句型、修辭、題目、學生任務、答案與評量文字，一律視為教學關鍵文字。若圖片模型無法保證逐字正確，這些文字必須由可控的正式文字層建立。

## 合成流程

1. 圖像層只生成背景、情境、人物、物件與不含關鍵文字的版面空間。
2. 移除、遮蔽或避免圖像層中的偽字、錯字與無意義字形。
3. 從 Render Request 的 `verified_text` 建立單一標題、句子、詞語、注音或提示的透明文字圖片元件。課文正文與一般教學提示可使用已核准的 `LXGWWenKaiTC`；形近字、注音與部件拆解固定使用 `SourceHanSansTC`，不可默默改回未核准字型。
4. 逐元件檢查原文、字形、注音、標點、斷行、透明邊界與實際尺寸，保存元件校對紀錄。
5. 將通過校對的元件依視覺構圖嵌入底圖，再扁平化為整頁圖片；元件不可回退成一般逐行文字框。課文頁優先合成為一個連續閱讀區，配合紙張、筆刷、書頁、旁註或漫畫內部分格形成完整教材畫面，不得退化成一個框一個框的卡片排列。
6. 重新讀取最終 PNG／PDF／PPTX 頁面，逐字核對來源。

## 通過條件

- 關鍵文字零錯字、零簡體、零漏字。
- 注音、標點、括號與題號均與來源一致。
- 文字與背景有足夠對比，列印或投影尺寸可讀。
- 圖像層不得出現會讓學生誤讀的殘留偽字。
- 每個正式文字元件都有可追溯來源、字型檔與校對狀態。
