# 國語圖片式語文頁規則

版本：1.2

本參考文件供 `presentation-engine` 與 `vmax-image-renderer` 在製作國語圖片式簡報時使用，涵蓋課文循環、文意理解、修辭、句型與成語頁。形近字與多音字的專門規則仍以 `skills/character-group-visual-comparison/SKILL.md` 為準。

## 1. 共通教學邏輯

所有頁型優先採用：

> 課文證據 → 視覺理解 → 教學發現 → 學生應用

圖片先呈現事情、動作、關係或情緒，再讓學生看見教學概念。正式術語、公式與解釋不可先取代課文或情境。

每頁只保留一個主要教學焦點，最多搭配一個必要追問或操作提示。學生頁不得直接呈現文字答案、完整結論、正確選項或講者備註；可以使用非答案性的圖片、概念圖示、視線、箭頭、圈選、底線與找證據提示。

## 2. 圖片與文字分工

### 圖片模型負責

- 人物、場景、動作、表情、物件與手繪裝飾
- 留白、視線、動線、前後變化與情境關係

圖片模型不得承載關鍵教學文字，也不得自行生成課文、注音、形近字、成語、修辭名稱、句型、題目、部件拆解或對話文字。

### 受控文字層負責

- 課名、頁碼、課文原文與課文片段
- 形近字、部件、注音、詞語與成語
- 修辭名稱、句型、文意問題、教學提示與對話文字

受控文字層必須逐字可追溯到來源或教師核准內容。文字不能因為受控就退化成制式簡報；須依插圖留白、角色視線、動作路徑、紙條、書頁、招牌、筆刷底色或對話泡泡共同構圖。

禁止：四欄平均文字框、每頁固定標題加內容框、大量白色矩形卡片、文字全部集中在下方、背景完成後硬貼大量文字、文字框遮住角色或重要動作。

### 2.2 字形、字體與校對文字圖片元件

學生可見的國字、課文、形近字、注音、成語、句型、修辭名稱、題目與正式例句，字形正確優先於裝飾效果。課文正文與一般教學提示可使用已核准、支援臺灣繁體字形的 `LXGWWenKaiTC`（文楷）；形近字、注音與部件拆解固定使用 `SourceHanSansTC`（思源黑體 TC）。不可默默改回未核准字型。

圖片式簡報的正式文字不採「一般字型逐行貼上」作為最終合成方式。應採 `VERIFIED_RASTER_TEXT_COMPONENTS`：

1. 從 `Verified Teaching Text` 取出單一標題、句子、詞語、注音或提示元件。
2. 以指定正式字型、字重、顏色與行距，渲染成透明背景的獨立文字圖片元件。
3. 逐元件檢查字形、注音、標點、斷行、邊界與透明區，並保留元件檔與校對紀錄。
4. 再依插圖留白、角色視線、紙條、筆刷痕跡、箭頭或場景物件嵌入整頁畫面，最後扁平化輸出。

文字圖片元件仍必須由可控文字工具產生，不能交給圖片模型生成；「圖片化文字」不是允許錯字，也不是把錯字當成手繪風格。若元件校對失敗，只重建受影響元件，不重生已確認底圖。

字體角色固定如下：課文正文與一般教學提示使用已核准的 `LXGWWenKaiTC` Regular／Medium；形近字、注音與部件拆解使用 `SourceHanSansTC` Regular／Medium。兩類文字都必須先渲染成透明圖片元件並逐字校對；若字型或注音支援不可用，標記 `TEXT_RENDERING_RISK` 並停在當前階段。

## 2.1 課文圖片的教學功能與證據

課文圖片不是裝飾，而是課文理解的視覺證據。每張圖至少完成一項功能：交代人物／地點／時間、呈現事件、表現動作或情緒、暗示段落重點、連結關鍵詞、呈現前後變化，或幫助學生推論文意。

圖片可以先引發觀察，再由文字補足理解，但不得增加課文沒有的事件、人物關係、情緒結論或因果。每張圖在進入 Render Request 前都要建立可追溯的 `image_evidence_map`：

```yaml
image_evidence_map:
  source_paragraph_or_unit:
  source_sentence_or_keyword:
  visual_facts_from_source: []
  reasonable_visual_supplements: []
  prohibited_inferences: []
  student_observation_prompt:
```

若無法說明圖片對應哪一段、哪一句或哪個關鍵詞，不得使用。合理補充只能服務場景完整性，不得變成新的劇情。

### 三種圖片功能

- **情境圖**：交代背景、時間、地點或人物，文字少，讓學生先進入故事。
- **動作圖**：畫出奔跑、遊戲、同時反應、時間推進、回頭揮手等正在發生的動作與變化，不使用站立擺拍代替動作。
- **理解圖**：把抽象語意轉成可觀察線索，例如用夕陽、影子、鐘面與活動變化呈現時間變快，用回頭、揮手與離開呈現依依不捨；不得只按字面直譯成語或抽象概念。

若課文段落包含清楚的事件序列、前後變化或學習歷程，可採 3–4 格連環漫畫作為課文旁的理解插圖。每格必須對應原文中的人物、動作、事件或情緒變化，並以箭頭、視線或動線協助學生看出順序；漫畫不能取代完整課文原文，也不能把未經來源支持的情節補進畫面。此頁型應維持「完整原文一區＋較小漫畫插圖一區＋必要語詞解釋」的結構，漫畫比例依文字量適度縮小，不得為了滿版而壓縮閱讀區。

圖片不能一次把答案畫完。文意頁可以提供學生觀察所需的線索，但不得把主旨、人物心情、因果結論或正確答案用大字、標籤、箭頭或畫面配置全部指好。

### 各頁型的圖文配置

- **原文閱讀頁**：圖片交代完整場景，原文安靜清楚地放入留白、書頁或手繪閱讀紙；插圖不得壓縮正文。
- **關鍵詞回看頁**：圖片聚焦一個動作或細節，文字只保留必要片段，關鍵詞靠近對應圖像，不重貼全文。
- **文意理解頁**：圖片呈現問題情境，問題靠近人物／動作，證據文字靠近對應細節；不得讓左右兩區各自說不同的事。
- **修辭頁**：放大聲音、動作、速度、情緒或其他修辭效果，不只放人物站立圖。
- **句型頁**：呈現兩種情況、前後變化、共同結果或其他句型關係，不只放無關的單一情境圖。

### 圖片內文字

場景中可以有少量受控的招牌、書名、紙條、對話或物品標籤；課文原文、成語、形近字、注音、修辭名稱、句型、文意題與部件拆解不得交給圖片模型生成，必須由受控文字層加入。

### 圖片品質檢核

圖片應維持溫暖手繪感、清楚前中後景、自然動作、適度複雜度與主次關係；不要為了熱鬧增加無關人物，也不要生成滿版複雜圖後才硬塞文字。每頁插圖比例必須依教學功能變化：可採局部插圖、半頁插圖、兩個相互呼應的視覺物件或近滿版情境圖；近滿版只在能承擔主要理解功能時使用。課文閱讀頁可把正文放入場景中的書頁、練習本、航海日誌或手繪閱讀紙，讓文字成為構圖物件而非後貼文字框。角色外貌、服裝、比例與畫風必須符合已確認角色庫。

每頁完成後檢查：

1. 拿掉文字，學生是否仍看得出課文正在發生什麼？
2. 拿掉圖片，文字是否少了一部分理解線索？
3. 圖片和文字是否正在說同一件事？

若圖片只是裝飾、與文字各說各話、增加未授權情節或直接變成答案圖卡，標記 `SEMANTIC_IMAGE_MISMATCH` 或 `ANSWER_LEAKAGE_VISUAL`，停批等待教師決定。

## 3. 每頁文字層級

每頁最多分三層：

1. **主訊息**：唯一主要發現或教學焦點，可放在手繪紙條、筆刷底色、場景留白、對話泡泡或發現標籤。
2. **證據文字**：課文原句、關鍵詞、部件、成語行為、句型例句等，用來支持主訊息，不得比主訊息更搶眼。
3. **操作提示**：找一找、想一想、圈出來、哪裡不一樣等，短小清楚，不得變成整頁說明。

文字容器先依功能位置與插圖動線決定，再決定形狀；不以固定框框作為第一步。

## 4. 課文循環頁

課文循環頁不是重複投影全文，而是配合教學進度重新回看課文。可依本課需要選用以下梯度，不強迫每課固定五輪：

1. **初讀**：保留原文，先看懂內容與場景，不急著分析。
2. **關鍵詞回看**：標出動作、感官、情緒、時間、轉折或變化詞。
3. **段落功能**：觀察這一段寫了什麼、事情如何變化，以及和前後文的關係。
4. **全文線索**：串起時間線、情緒線、行動線、地點、事件發展或前後對比。
5. **主旨統整**：由事件、感受與關鍵證據回到作者想法。

規則：

- 保留課文原文、自然段／語意單位與原有順序。
- 同一自然段或連續課文段落應以一張連續閱讀區呈現；只為投影寬度換行，不得把每一句切成彼此獨立的色塊、卡片或教學小節。
- 課文頁優先採「單一閱讀區＋旁側理解插圖」；文字可放在一張自然紙面、淡色筆刷或場景留白中，但不得把課文、語詞與解釋拆成一個框一個框。
- 漫畫可保留自身的墨線與內部分格，但不得再把每格外加成獨立卡片；語詞解釋優先使用自由旁註、底線、箭頭或情境標記。
- 課文頁的詞語標示應直接回到原文位置：以核准色彩、底線或淡色圈選標出詞語，再在附近安排簡短詞語解釋；標示不能破壞段落的連續閱讀感。
- 文字過多時拆成連續課文頁，不改寫、刪節、摘要或重組段落。
- 每次回看優先新增一種標記，例如關鍵詞、動作詞、問題或統整句；不在同一頁塞入所有標記、修辭、句型、文意題與成語解釋。
- 標記使用淡色、底線、手繪圈選、箭頭或角色視線，不一次把全文畫滿。
- 插圖補充場景，不取代課文；課文正文仍是閱讀主體。

## 5. 文意理解頁

文意理解頁必須讓學生依課文證據思考，不是把題目排列在白底上。題目可涵蓋明確訊息、事件關係、人物感受推論、前後變化、作者想法與生活連結，不要求每題都抄找原句。

建議順序：

1. 情境畫面或角色引題。
2. 必要的課文片段、關鍵詞或證據圖示。
3. 一個主要問題，最多一個追問。
4. 學生口頭思考、選擇、連線、半完成句或短答。

問題要短，並靠近其證據。可以使用手繪紙條、問號路徑、小黑板、放大鏡、箭頭或留白區；不可使用大量編號題、考卷式排列或顏色直接暗示答案。

## 6. 修辭發現頁

固定順序：

> 課文原句 → 關鍵詞突出 → 看見特色 → 猜想效果 → 修辭名稱 → 小練習

原句必須完整或保留足以理解的連續片段。可用聲音符號、動作線、角色表情、文字放大、手繪圈選或情境畫面讓學生先感受到效果，再以小標籤、紙條或角色提示揭示名稱。

效果說明使用四年級能懂的短句，例如「讓畫面動起來」、「讓聲音好像真的傳過來」、「讓讀者更想知道答案」。每頁最多處理一種主要修辭，不做「修辭名稱／定義／例句」三欄表，不把原句切成無法理解的碎片。

## 7. 句型發現頁

固定順序：

> 課文例句 → 句意理解 → 關鍵詞對應 → 句型骨架 → 新情境 → 分層仿說／仿寫

課文例句比公式重要。可用相同顏色標示對應位置，並用手繪箭頭、紙條拼接、角色對話或路徑呈現結構；公式只是輔助，不得成為頁面主體。

仿說／仿寫依序提供：提示填空 → 替換詞語 → 替換情境 → 完整創作。投影頁以口頭發想與圖像引導為主，實際書寫線另由學習單處理；不得把仿寫區壓縮成角落小框。

## 8. 成語教學頁

固定順序：

> 情境畫面 → 猜意思 → 成語出現 → 口語語意確認 → 課文連結 → 實際應用

先呈現事情、動作、人物關係或前後變化，再揭示成語。成語情境不可只按字面直譯；必須看得出「同時發生、前後變化、努力競爭、爭論持續、不想離開、全部消失、主動追上或互相比較」等實際語意。

一般一頁一個成語；只有同一故事線、前後發展、對照關係、同一場景不同人物或課文連續出現時，才可一頁兩個。兩個成語必須由畫面與動線串起來，不可只是左右並排。

成語名稱可作手寫標籤、小旗子、紙條、對話泡泡或圖像旁發現卡，不得遮住關鍵畫面。成語不標注音；解釋只保留一句學生聽得懂的口語，例句短且優先連結課文或學生生活。不得做成語、解釋、例句三欄表，也不得堆放大量成語。

成語應用可採看圖選用、情境配對、判斷用法、改正錯誤用法、完成半句、生活例子或用成語說明課文人物；學生頁不直接放答案，也不把答案藏在插圖中。

## 9. 形近字頁分流

形近字頁沿用 `skills/character-group-visual-comparison/SKILL.md` 的專門規則。此共用規則只要求：大字、注音、部件、詞語與情境必須形成可讀關係；不可把形近字頁改成四格平均表、字典清單或圖片模型文字。

## 10. 代表頁與批次流程

不要逐頁全部停等，也不要先完成整套再回頭驗收。正確流程是：

1. 先為本課每個實際啟用頁型完成一頁代表頁。
2. 教師確認原文、唯一焦點、證據層、視覺構圖、角色定錨、文字層與投影可讀性。
3. 代表頁通過後，才可對同類頁面進行 5–8 頁小批次生成。
4. 每批逐頁檢查文字、圖文共同構圖、角色／風格一致性與答案可見性。
5. 發生錯字、原文遺失、文字像打字貼上、表格講義感、圖像誤導、角色漂移或文字溢出時，立即停批，列出受影響頁面與下游項目，等待教師決定。

代表頁通過不等於所有未展示頁面自動通過；批次檢查仍不可省略。教師確認前不得定稿、上傳或覆蓋雲端原檔。

## 11. 頁面檢核

- 主訊息只有一個，證據文字與操作提示層級清楚。
- 課文原文、成語、句型、修辭名稱、題目與對話逐字正確。
- 文字由受控文字層渲染，圖片模型沒有生成關鍵文字。
- 課文證據與問題靠近，插圖確實支援理解。
- 版面不是固定卡片、平均欄位、密集講義或背景圖加文字框。
- 圖像表達真正的動作、關係、情緒或前後變化，而非無關裝飾或字面直譯。
- 角色只在有教學功能時出現，且外觀、數量與動作符合角色庫。
- 學生頁無文字答案、講者備註或未核准知識。
- 尺寸、字級、換行、安全邊界與投影可讀性通過。
- 教師確認後才可定稿。

主要失敗碼：`TEXT_CYCLE_FOCUS_MISSING`、`COMPREHENSION_WITHOUT_EVIDENCE_PATH`、`RHETORIC_LABEL_FIRST`、`PATTERN_WITHOUT_SOURCE`、`IDIOM_LITERAL_IMAGE`、`SEMANTIC_IMAGE_MISMATCH`、`TYPED_TEXT_LAYOUT_FAIL`、`REPRESENTATIVE_PAGE_NOT_APPROVED`。
