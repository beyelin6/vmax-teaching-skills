# NE04｜高密度靠縮字硬塞

## failure_pattern
資訊過量時只靠縮字、縮行距、縮作答區或整頁縮放解決。

## symptoms
- 字級逼近或低於安全紅線
- 行距過密
- 框內 padding 幾乎消失
- 學生沒有足夠書寫空間
- 整頁輸出被縮小

## why_it_fails
頁數看似控制住，但實際閱讀與使用功能失敗。

## fix
依序：移除無功能裝飾 → 重分資訊區 → 合併真正相關內容 → 去除實際重複 → 調整間距 → 重選版型 → 拆頁。安全字級只做最後的小幅微調。

## do_not_overgeneralize
高密度不等於一定拆頁；若透過資訊編輯與更合適版型可以安全容納，仍可保留單頁。
