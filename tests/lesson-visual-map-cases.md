# Lesson Visual Map Regression Cases 1.0

目的：驗證 `core/visual/lesson-visual-map.md` 不會退化成固定模板、文字牆或提前爆雷。

## Case 1｜童詩：水陸小高手
Text signal：兩首童詩、六詩節、運動動作、聯想、類疊、節奏、情緒感受。

OPEN 預期：
- 可採「水／陸雙軌意象旅程」。
- 圖像呈現游泳與直排輪的主要動作／想像轉化。
- 關鍵詞可到「動作、聯想、節奏、感受」層級。
- 不提前把完整主旨或所有修辭答案寫滿。
- primary grammar 可為 Motion Grammar 或 Figurative Transformation；不是固定 Relationship Network。

CLOSE 預期：
- 可整理文體、兩首詩的結構、聯想／類疊／短句節奏與核心感受。
- Knowledge Lab 只取與整課理解高度相關的焦點，不把所有生字／成語塞進圖。

FAIL：
- 只畫一棵中心寫「水陸小高手」的放射樹。
- 每個生字一個分支。
- 開頭直接公布完整主旨與所有修辭答案。

## Case 2｜寫景文
Text signal：遠近、上下、移步換景。

預期：
- Map 應保留作者觀看順序。
- primary grammar 優先 Moving Viewpoint 或 Spatial Depth。
- 可以像一張「鏡頭／路徑地圖」，不必長成傳統心智圖。

FAIL：把每段摘要做成平行資訊卡，失去觀看路徑。

## Case 3｜人物記敘文
Text signal：透過事件、語言、行動推論人物特質。

OPEN 預期：
- 顯示事件與證據節點，但可把「人物特質」保留成待發現位置。

CLOSE 預期：
- 可以形成「事件證據 → 人物特質」關係。
- primary grammar 可為 Evidence Lens。

FAIL：OPEN 直接寫出「他是一個勇敢又善良的人」。

## Case 4｜說明文：自然科普
Text signal：分類、結構、流程或因果。

預期：
- 選 Concept Model / Whole-Part / Process-Causality。
- 圖像本身應幫助學生看見分類或運作關係。

FAIL：只把五個小標題放在五個泡泡裡。

## Case 5｜議論／說理
Text signal：觀點、理由、證據。

預期：
- CLOSE 可形成「觀點 → 理由 → 證據 → 結論」支持關係圖。
- OPEN 若論點需學生自行辨認，先顯示問題與證據來源，不提前填完結論。

FAIL：把整篇摘要縮成很小的字放一頁。

## Case 6｜極短文本
Text signal：結構單純、無多層關係。

預期：`lesson_visual_map.status = OFF` 合法。

FAIL：為了每課固定格式硬做一張。

## Global Gate

所有 Case 必須同時滿足：
1. 5–10 秒能抓到主軸。
2. 文字不需縮小到影響中年級閱讀。
3. 圖像有認知功能，不是裝飾。
4. OPEN 不爆雷。
5. CLOSE 能支援複習。
6. 不固定使用樹狀／放射狀心智圖。
7. 正式中文字由可靠文字層提供並通過 strange-Chinese scan。
