# 跨平台行為驗收：待實際平台執行

以下是人工／模型執行案例，非自動測試已通過的宣稱。每個平台記錄安裝包版本、可用工具、實際讀檔與寫檔證據、產物及結果；無法進入該平台記 NOT_RUN。

| 案例 | 輸入情境 | 預期行為 |
| --- | --- | --- |
| 新課離線 | 完整包、上傳教材、無 Drive、有持久檔案 | 初始化 LOCAL，完成 VP1 整包審核；不要求 GitHub 或舊 State |
| 既有 P05 | 有綁定 State、P01–P04 核准與 P05 母稿 | 只續作 P05，不重新分析已核准來源或重問角色 |
| Drive 中斷 | 有已核驗 revision，遠端不可寫 | 保存 pending 教師事件，不切換後端、不宣稱同步；繼續獨立草稿 |
| 恢復有衝突 | 遠端 revision 已超過 pending base | 保留兩份，禁止直接覆蓋，集中處理衝突 |
| VP1 核准 | 同一包所有範圍有明確核准 | 保存事件後完成 VP2 整合方案，不逐題停 HOLD |
| 局部修字 | 插圖角色已核准，只有文字錯字 | 引用原圖局部修字；無編圖工具就交接，不重生整頁 |
| 缺生圖 | 已核准逐頁稿、只有文字能力 | IMAGE_HANDOFF_READY，不產生 RENDER_VERIFIED 假成品 |
| 對話移交 | 無持久檔案能力 | 輸出明確移交包／區塊並標示待保存；不假裝 Drive 已寫入 |
| 獨立短文單 | 已有核准課程內容 | 路由短文單技能，不重開整課簡報流程 |

自動測試只檢驗包完整性、單入口、引用改寫及 checkpoint 資料契約；上述階段行為與圖片品質仍須實際執行。
