# V-MAX Teaching Skills

V-MAX 國語教材轉錄、課程設計、NotebookLM 與簡報生成技能庫。

## 核心原則

- Skill 保存方法與工作流。
- Library 保存可重用的風格、角色、版型與教學資源。
- Course 保存每一課的教材事實、教師決策與當課設定。
- Output 保存每一課的生成成果。
- 每課內容、頁數與教學模組都必須動態判斷，不使用固定頁數模板。

## 初始模組

- `chinese-textbook-transcriber`
- `chinese-lesson-designer`
- `chinese-slide-architect`
- `chinese-extension-materials`
- Style Library
