# V-MAX Image-first Hybrid Renderer

## 定位

V-MAX 的簡報輸出採「圖片式整體構圖優先 + 文字正確性保護」的混合式 Renderer。

核心原則：

> 不要為了可編輯而犧牲整體構圖；也不要為了漂亮而犧牲中文字與教學內容的正確性。

教師不需要手動後製。

---

## 1. 為什麼採 Image-first

目前生成式影像在整張投影片的：
- 文圖整合
- 構圖
- 留白
- 視線節奏
- 插畫與標題協調
- 情緒與世界觀一致性

往往比傳統程式化 PPT 排版更自然。

因此 V-MAX 不要求每張投影片都先拆成「圖片區 + 文字區」再拼裝，而是先以整張投影片作為一個完整視覺畫面設計。

---

## 2. 兩種輸出層並存

### A. Image Composition Layer
負責整張畫面的視覺完成度：
- 插圖
- 場景
- 背景
- 視覺框架
- 標題位置
- 文字與圖像的相對位置
- 留白
- 木牌、紙張、對話框、標籤等 UI 外觀

可用 Image Generator 先生成完整「視覺稿」。

### B. Verified Teaching Text Layer
負責教學內容正確性：
- 課文原句
- 生字
- 注音
- 語詞
- 成語定義
- 句型與修辭標記
- 題目與學生任務

這些文字必須來自來源資料／教師確認內容，不得由圖片模型自行改寫。

---

## 3. 三種 Render Mode

### Mode 1｜Visual Image Slide
整張投影片以高品質圖片式構圖輸出。

適合：
- 封面
- 情境進場
- 童詩意象
- 故事／成語分鏡
- 高潮停格
- 視覺導覽

條件：
- 圖中文字必須經過內容比對與人工／系統視覺校對。
- 若中文字全部正確，可直接保留圖片式投影片。
- 不要求所有文字可編輯。

### Mode 2｜Hybrid Overlay Slide
先生成完整圖片式構圖，再把需要高正確性／可編輯性的核心文字，以 PPT Native Text 疊在同一張畫面上。

適合：
- 課文原句
- 生字與注音
- 形近字／多音字比較
- 成語正式定義
- 題目
- 需要教師之後修改的文字

重點：Native Text 必須「疊在圖片構圖裡」，而不是被丟到圖片旁邊。

### Mode 3｜Native Analytic Slide
以真正的 PPT 文字與圖形為主，圖片只做輔助。

適合：
- 高密度形近字比較
- 多音字表格
- 結構圖
- 練習／評量
- 需要高度編輯的教師工具頁

---

## 4. 預設選擇邏輯

```text
先問：這頁最重要的是整體視覺經驗，還是文字精準操作？

若視覺經驗優先
→ Mode 1

若視覺與文字都重要
→ Mode 2（預設主力）

若文字關係與編輯性優先
→ Mode 3
```

V-MAX 不應把所有頁面強迫成同一 Render Mode。

---

## 5. 關鍵設計：Reference Composition

若採 Mode 2，流程不是：

```text
先畫背景 → 再隨便塞文字
```

而是：

```text
1. 先用完整內容生成「整張視覺構圖參考稿」
2. 取得文字在畫面中的理想位置、比例、框體、留白與閱讀順序
3. 生成乾淨的視覺背景／UI 元件
4. Renderer 按參考稿位置重建正式文字層
5. 比對最終畫面是否保留原本的美感與閱讀節奏
```

Reference Composition 是視覺藍圖，不是內容真值來源。

---

## 6. 中文文字的驗證規則

圖片模型可以參與「文字視覺構圖」，但不得成為文字內容的唯一來源。

若圖片式投影片含中文字，需逐項比對：
- 是否與來源字串完全一致
- 是否有錯字／缺字／多字
- 標點是否正確
- 注音是否正確
- 成語與定義是否正確
- 題目是否被改寫

只要有任何錯誤：
- 不得直接交付該張圖片式文字
- 改用 Mode 2 重建正式文字層，或重新生成

---

## 7. PPT Overlay 必須保留「圖文一體感」

Native Text 不是放在圖片外面，而要成為畫面的一部分。

可使用：
- 文字直接壓在天然留白
- 半透明紙張／卡片
- 木牌／標籤／對話框
- 圖中的筆記頁
- 地圖標記
- 箭頭與引線
- 大字與插圖交錯

禁止：
- 固定左圖右文
- 圖上方一條標題、下方整塊白底文字的機械模板
- 為了 native text 把原本漂亮的構圖拆散

---

## 8. 可編輯性不是唯一品質指標

對課堂簡報而言，優先順序為：

1. 教學內容正確
2. 學生看得懂
3. 整體視覺與閱讀路徑好
4. 中文呈現正確
5. 教師必要時可修改關鍵文字
6. 全部元素是否 100% 可編輯

因此 V-MAX 不要求所有插畫、裝飾、視覺框架都可編輯。

---

## 9. 建議預設

### 閱讀／童詩／故事主體
Mode 1 + Mode 2 為主。

### 語詞／句型／修辭
Mode 2 為主，讓文字和課文畫面融合。

### 生字／形近字／多音字
Mode 2 或 Mode 3，依比較密度決定。

### 成語
情境／漫畫部分可 Mode 1；正式成語、定義與例句使用 Mode 2。

### 評量／練習
Mode 3 為主。

---

## 10. 教師交付原則

最終交付的 PPT 應已完成所有圖文合成。

教師不需要：
- 手動把文字搬到圖片上
- 自己對齊文字與圖
- 自己遮掉 AI 錯字
- 自己重做版面

若 V-MAX 無法完成某張的圖文合成，該張視為 Renderer 未完成，而不是把後製工作交給教師。

---

## 核心金句

> 圖片式投影片負責讓孩子想看，正式文字層負責讓孩子看對；最好的 Renderer 要同時做到兩件事。
