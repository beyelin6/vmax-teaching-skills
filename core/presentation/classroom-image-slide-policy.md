# V-MAX Classroom Image Slide Policy 1.4

## 定位

本政策定義國語課「教師口述用圖像式教學簡報」的全域標準。它適用於正式簡報、圖片式投影片、NotebookLM / ChatGPT / Gemini / Canva renderer handoff；不適用於學習單、講義、考卷或學生書寫單。

核心原則：

> 投影片只放學生此刻需要看見的內容；完整解說、答案、來源細節與備課資訊留在教師層。

> 圖像式簡報不是把字貼在漂亮背景上，而是讓畫面、文字、留白與觀看路徑一起服務教學焦點。

---

## A. Product Boundary

簡報畫布必須先由教師在 `4:3` 與 `16:9` 中選定，再依 `core/presentation/canvas-lock-policy.md` 鎖定比例、實際像素與輸出格式。選定後各頁可依內容調整構圖，但不得自行切換比例；不得改用 `3:2`、`9:16`、A4 或其他未核准畫布。A4 學習單與短文單由各自技能管理，不屬本政策。

畫布選擇、實際像素、方向、安全邊界與素材等比處理，必須在視覺 prompt、角色構圖與文字排版前完成。任何缺少或互相衝突的畫布設定，都必須停在 `CANVAS_SPEC_BLOCKED`，不得先試跑。

學生可見投影片不得退化為：

- 學生講義或滿版資訊整理表。
- 學習單、書寫單、填空區或投影版考卷。
- Canva 模板感的卡片拼貼。
- 滿版濃色底、滿版童書圖或裝飾過多的漂亮講義。

投影片應支援教師上課口述：讓學生看見課文、重點、畫面證據、討論焦點、朗讀節奏、語文特色與遷移方向。

學生頁可以有簡短、非答案性的任務提示或理解引導語，前提是它服務學生當下的觀看／作答；不得把答案先標出、把教師講者備註放到學生頁，或露出教師專用的教學意圖、解題步驟與來源資訊。

---

## B. Visual Atmosphere Defaults

除非教師或 Style Recipe 另有核准，本類簡報預設：

- 乾淨白色或暖白色背景。
- 明顯留白。
- 一頁一個主要視覺焦點。
- 局部主畫面，而非每頁滿版塞滿。
- 主意象明確，次要區域較淡。
- 畫面有前景、中景、背景或濃淡層次。
- 一般頁優先一個主畫面；多圖時必須有清楚主次、圖間呼吸與自然邊界。

這些是預設方向，不是所有課的固定美術風格；若課文需要探險、科普、古典、新聞或其他風格，可由 Style Recipe 改寫，但仍須保留「少而清楚、口述輔助、圖文共同構圖」的原則。

## C. Slide Density Rules

- 一頁只承擔一個主要教學焦點。
- 同頁若同時要求學生處理課文、語詞、修辭、句型、深究、練習、小提醒、小挑戰，視為過度擁擠，必須拆頁或改成 Reveal。
- 不用縮字解決內容過量；寧可減字、拆頁或改由教師口述。
- 一般頁不必重複課名大標；封面、大單元轉場與重要統整頁才使用大標題。
- 句型、修辭、深究頁以當頁教學焦點作主標，不堆疊抽象章節名。
- 不留書寫線、填空區或大面積作答空白；需要書寫時改由學習單或獨立任務承接。
- 插圖也受密度規則約束：一般頁預設一個主畫面，輔助視覺數量依內容與頁面功能決定；心智圖、路線圖、事件地圖、流程圖與漫畫可以使用較多輔助視覺，但必須有主次、群組、閱讀路徑與自然間距。圖片若互相相切、黏連或形成無法閱讀的縮圖牆，必須減圖、拆頁或改成有意義的漫畫分格。
- 滿版插圖只有在頁面主題確實需要且文字閱讀區、留白與投影可讀性仍通過時才可使用；不得因生圖結果很漂亮就直接採用。
- 多圖頁須在 Render Request 中記錄 `image_layout_plan`、`visual_density_profile`、`primary_visual_id`、`supporting_visual_ids`、`gutter_policy` 與 `split_if_overloaded`。

## D. Global Page Types

### 課文＋詞語頁

- 完整呈現當前自然段、意義段或詩節的原文。
- 搭配情境插畫或意象圖，但不得干擾閱讀。
- 詞語在原文語境中理解；不得同頁再塞修辭、句型、深究與練習。
- 核心詞可用少量標色或淡色螢光筆；不整段全上色。

### 語文特色頁

- 一頁只處理一個真正重要的句型、修辭、類疊、節奏或寫法。
- 先讓學生感受效果，再由教師口述名稱。
- 不先做術語定義表。
- 可結合朗讀節奏、動作、視覺節拍或比較畫面。

### 文意深究頁

- 一個主問題，最多一個追問。
- 搭配大幅情境或證據圖。
- 詳細解說與參考答案留在教師層。
- 可加頁，不硬塞。

### 字詞頁

- 形近字一頁一組為優先，最多兩組。
- 多音字一頁一字為優先。
- 每組需有大字、差異部件或讀音標示、代表詞、語意情境圖與最小必要注音。
- 不做滿版字表、多欄背誦表或講義式整理。

### 成語頁

- 必須保留成語名稱、簡短釋義、生活例句與對應情境圖。
- 可用分格漫畫或對照畫面，但格數由語意決定。
- 例句不能消失。
- 不預設典故考據型頁面，除非教師明確指定。

### 仿作／遷移頁

- 以口頭發想與圖像引導為主。
- 不留寫字線。
- 可使用「動作 → 聯想 → 感受」或同課已核准的遷移結構。

## E. Reading Act Construction

對詩歌、短文或分段明確的課文，預設以小節／自然段為施工單位：

```text
先讀懂：課文＋詞語
→ 再看語文特色：句型／修辭／節奏／寫法
→ 再深究意思：問題、證據、推論
```

這是施工順序，不是硬性三頁模板。若某段沒有值得獨立處理的語文特色或深究，可合併或省略；若深究需要更多呼吸，應加頁。

執行時先讀當課 Lesson Baseline 或施工總表，再鎖定當前小節，一次規劃該小節的頁組，最後逐頁施工。不得跳過核准母檔直接憑印象生圖或排版。

---

## F. Text And Marking

- 學生可見文字只使用繁體中文、正式標點與必要的台灣繁體注音符號。
- 不出現拼音、英文標音、日文假名或不明亂碼標音。
- 課文頁原則上不標注音；注音只用於需要辨讀的生字、多音字或教師指定項。
- 一頁主重點色以一至兩種為主，必要時加一種輔助色。
- 顏色服務辨識與證據連結，不作裝飾。

### 課級頁碼系統

- 頁碼是整課簡報的導覽元件，不是每頁自由放置的裝飾。
- 每課在正式渲染前，先由已選風格決定並鎖定 `page_number_system`：位置、容器／形狀、字體角色、字級、顏色、格式（例如 `01` 或 `P01`）、是否搭配課名／圖示與特殊頁的顯示規則。
- 同一課所有頁預設沿用同一位置與樣式；封面或轉場可以依已核准的 `visibility_policy` 省略，但不得自行換到另一角落或改成另一套格式。
- 頁碼使用簡報序號，不冒用教材 PDF 頁碼或課本印刷頁碼；來源頁碼另存在 source metadata。
- 頁碼系統鎖定後若需改位置或樣式，必須建立新版本並列出受影響頁面，不得在續跑時靜默漂移。

## G. Production Flow

圖片式簡報固定採：

```text
先規劃頁型與學生焦點
→ 產生無字或少字插畫底圖
→ 以 Verified Teaching Text 逐層渲染繁體中文與注音圖片層
→ 檢查教室投影可讀性
→ 只修錯的層或局部，不因小錯整頁退回講義感
```

課文、生字、注音、成語定義、題目與正式例句不得交給生圖模型自由生成。圖片式簡報預設將每段正式文字渲染為獨立可驗證圖片層；若圖片模型產生錯字，移除圖片中文字並重建對應文字層。

## H. Lesson Baseline Handling

單課施工總表、逐頁架構、角色指定、詞語清單與視覺方向屬於 `Lesson Baseline`。

- 進入簡報製作、修圖、生圖或排版前必讀當課已核准 Baseline。
- Baseline 可持續追加新通則、頁型、通過基準圖、淘汰方向、角色限制、標色規則與生圖流程修正。
- 不覆蓋已確認決策歷史；新增決策應帶日期、來源或教師確認狀態。
- Baseline 只約束該課，不得自動升級為跨課全域規則。

## I. Approved Visual Benchmark Handling

若 Lesson Baseline 或教師提供「核准樣張／樣品感／代表頁 PDF、PNG、PPTX」，必須登錄為 `Approved Visual Benchmark`。Benchmark 是視覺品質與頁型節奏的參考，不是教材內容來源；不得照抄頁面、竄改課文或把單課細節寫入全域規則。

使用方式：
- 先萃取 Benchmark 的可遷移特徵：留白、文字密度、局部插畫比例、角色使用、標色方式、頁型節奏。
- 代表頁驗收前必須產生 `benchmark_alignment`，逐頁說明如何對齊 Benchmark。
- 全課量產時每一批都要檢查是否偏離 Benchmark；偏離時停止量產並回到代表頁修正。
- Benchmark 不要求像素級複製；內容、詩節、角色與構圖可依本課調整，但「感覺」不可漂移。

通用核准感範例：
- 白底或暖白底，有明顯呼吸感。
- 局部清新水彩主畫面，一頁一個主要視覺焦點。
- 課文、語詞、注音與可讀文字以後製文字層完成，不交給生圖模型自由生成。
- 只用少量重點色服務教學焦點；課文中被標示的詞與詞語卡保持同色連結。
- 角色只在提問、提醒、收束、學生思考等功能點出場；不能變成每頁裝飾。

Benchmark 對齊五軸：
1. 留白與呼吸感。
2. 文字密度與教師口述比例。
3. 局部插畫、前中背景層次與一頁一主畫面。
4. 角色功能性、尺寸與干擾度。
5. 講義感／卡片牆感／模板感是否被避免。

失敗訊號：
- 只把字放到背景圖上，缺少圖文共同構圖。
- 變成三欄知識卡、滿版表格、小提醒長條或漂亮講義。
- 插圖滿版壓迫閱讀，或角色搶走課文焦點。
- 為了「圖片式」而犧牲課文、注音、生字或詞義準確性。

## J. Quality Signals

若出現以下情況，視為需修正：

- 學生頁像講義、考卷、表格整理或學習單。
- 角色只是填空位，拿掉不影響理解。
- 同頁出現三個以上主要認知任務。
- 圖像移除後仍是一張完整普通文字簡報。
- 教師需要自己搬字、校正課文、整理注音或重排版面。
- 全課頁組未依當課 Baseline 逐節推進，導致前後風格或教學節奏漂移。
