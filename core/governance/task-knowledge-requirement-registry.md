# V-MAX Task Knowledge Requirement Registry 1.0

各平台必須以本表為 Coverage Diff 最低基線；可依該課增加需求，不得自行刪除必要項。

## Pre-study Worksheet

課次與教材定位、文體、課文結構、核心文意、正式生字、認讀字狀態、形近字、多音字、核心語詞、教師手冊課前重點、題目答案證據、學生可能困難。

## Post-lesson Writing Worksheet

核心詞語與來源、可入文語詞、正式句型、修辭、寫作特色、文體結構、遷移目標依據、適齡寫作困難與教師引導。

## Presentation

Teacher Intent、主旨與段落證據、關鍵事件／關係、Knowledge Selection、語詞／句型／修辭原文證據、閱讀理解與答案、學生迷思、教師引導、下游不可遺失節點。

## Lesson Plan / Assessment / Activity / Image

- Lesson Plan：核心知識、目標、教師手冊重點、學生困難、教學順序、評量與差異化證據。
- Assessment：目標、可評量節點、題目來源、答案判準、常見迷思與難度線索。
- Activity：對應節點、先備知識、學習目的、預期產出與教師統整依據。
- Image：對應教材節點、正式繁中、人物／情境事實、不可改寫文字及視覺關係。

## Coverage 狀態

`AVAILABLE_AND_SELECTED / AVAILABLE_NOT_SELECTED / N/A_SOURCE_NOT_PRESENT / EXCLUDED_BY_TEACHER / MISSING_FROM_LKB / INSUFFICIENT_EVIDENCE / AGENT_OMISSION`

只有 `MISSING_FROM_LKB / INSUFFICIENT_EVIDENCE` 觸發 LKB Patch；`AGENT_OMISSION` 應修正執行結果。
