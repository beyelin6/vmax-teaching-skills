# V-MAX Teaching Skill Selection Policy 1.1-draft

## 定位
V-MAX 從 approved LKB、學習難點與 Teacher Intent 中選擇「最低必要」教學技能；技能為理解服務，不為特效服務。

> 教學技能先於視覺工具。

---

## 1. Skill Selection Inputs

選技能前至少需要：
- approved LKB
- 文體／文本結構
- 教師手冊一課一重點與教學提醒
- 學生可能卡點
- 語文知識與預習歷程
- 核心文意／閱讀任務
- Teacher Intent / Lesson Map / Session Map（若已成立）
- 可用課堂時間與既有 scope constraints

此階段不要求 Lesson Budget Final，也不依精確頁數選技能。

合法順序：

`learning difficulty → skill selection → lesson budget draft → Gate A`

---

## 2. Minimum Necessary Skill Set

每個候選技能都必須回答：
1. 解決哪個學習難點？
2. 拿掉後少理解什麼？
3. 是否與其他技能重複？
4. 是否值得佔用有限課堂時間？

若無法回答，降 FLEX / PLUS 或刪除。

---

## 3. Core Skill Vocabulary

- `COMPARE`：比較文本元素、字詞、觀點、場景或結構。
- `INFER`：由文本證據推論未直接說出的訊息。
- `STRUCTURE`：辨識文章／段落組織與功能。
- `STAGE`：把劇本、對話或事件轉成角色／臺詞／舞臺提示的可觀察關係。
- `PROBLEM_LOOP`：追蹤問題→思考／預測→嘗試→結果→新問題。
- `STORY_ARC`：掌握故事發展、轉折、高潮與結局。
- `CHARACTER_EVIDENCE`：用語言、行動、反應等文本證據支持人物理解。
- `TRANSFER`：把方法遷移到新文本、生活或產出。
- `RETURN`：必要時回原句／原段驗證理解。

`PREDICT / VERIFY / REVEAL` 為互動語法；可服務多種 Teaching Skill，不必各自升格成整課核心技能。

---

## 4. Skill → Visual Tool

技能確定後，才選畫面工具。

例：
- COMPARE → 並列／對照／雙場景
- INFER → evidence→inference／線索聚焦
- STRUCTURE → 流程／分支／地圖／段落骨架
- CHARACTER_EVIDENCE → 證據卡／人物中心圖
- STORY_ARC → 故事路徑／轉折節點
- STAGE → Stage View

禁止：「想做時間軸，所以找內容塞進去。」

---

## 5. Interaction Selection

可用：
- `PREDICT`
- `VERIFY`
- `REVEAL`
- `RETURN`

一頁可有兩個有層次問題，只要同屬一個 cognitive scene，例如：

`找證據 → 推論`

不可把無關任務硬塞同頁。

---

## 6. Text Anchor Policy

重要閱讀教學必須保留可追溯 `Text Anchor`：
- 課文原句
- 原段
- 關鍵詞
- 教冊指定文本證據

視覺、情境、角色對話不能取代 Text Anchor。

### RETURN 啟動條件
只在：
- 推論需要文本證據驗證
- 圖像可能造成理解漂移
- 比較後需確認原文差異
- 目標本身是找證據
- 教師需把討論收回文本

若畫面已保留足夠 Text Anchor 且沒有漂移風險，不機械增加 RETURN 頁。

---

## 7. Skill Density / Budget Draft

Teaching Skill Selection Lock 完成後，交給 Lesson Budget Draft 判斷：
- MUST：核心不可缺
- SHOULD：有明顯價值，可視時間調整
- COULD：延伸／挑戰／PLUS

新增技能必問：

> 新增的是理解，還是只新增活動？

只是形式不同但理解相同，不增加核心技能。

---

## 8. Spiral Learning

同一知識可跨教材深化：

`PREVIEW → CORE_REINFORCE → RECOGNIZE → APPLY / TRANSFER`

例如形近字／多音字在預習後，正式課堂仍可 COMPARE、RECOGNIZE、APPLY；不得因「做過」自動刪除。

---

## 9. Stop Rule

當：
- 核心卡點已被覆蓋
- MUST 已有對應技能
- 新技能只重複相同認知操作
- 新技能會擠壓核心文本時間
- 新技能主要服務特效／活動而非理解

停止增加技能。

---

## 10. Gate A Teacher Summary

自然語言呈現：
- 本課最需要孩子學會什麼
- 最可能卡在哪裡
- 核心技能為何
- 哪些內容刻意不做
- Budget Draft 如何分配

Gate A confirmed 後，核心 Skill Set 成為 downstream invariant；Scenario / Style / Extension 若要新增核心技能，必須重開 Gate A 或明確重平衡 Budget，不得偷偷加課。

---

## 核心金句

> 先回答「孩子哪裡會卡」，再回答「用什麼技能教」；最後才回答「畫面要怎麼長」。
