# V-MAX Teaching Skill Selection Policy 1.0-draft

## 定位

本規則定義 V-MAX 如何從 Lesson Knowledge Base 與學習難點，選擇「最低必要」的教學技能，而不是把所有可用技巧都塞進一課。

核心原則：

> 教學技能先於視覺工具。
>
> 技能是為了解決學生理解上的任務，不是為了讓簡報看起來豐富。

---

## 1. Skill Selection Inputs

選技能前至少需要：
- 文體／文本結構
- 教師手冊的一課一重點與教學提醒
- 學生可能卡點
- 語文知識點與預習單已接觸內容
- 核心文意／閱讀任務
- Lesson Budget
- Teacher Intent Lock（若已成立）

禁止只依「這篇是故事／說明文」就機械套技能模板。

---

## 2. Minimum Necessary Skill Set

每個候選技能都必須回答：
1. 它解決哪一個學習難點？
2. 如果拿掉，學生會少理解什麼？
3. 它是否與另一技能重複？
4. 它是否值得佔用一個認知場景／頁面？

若無法清楚回答，降為 FLEX／PLUS 或刪除。

---

## 3. Core Skill Vocabulary

目前 v1 可使用但不限於以下技能：

- `COMPARE`：比較兩個以上文本元素、字詞、觀點、場景或結構。
- `INFER`：由文本證據推論未直接說出的訊息。
- `STRUCTURE`：辨識文章／段落的組織方式與功能。
- `STAGE`：將戲劇、對話或事件轉成可觀察的舞臺／場景關係。
- `PROBLEM_LOOP`：追蹤問題→行動→結果→新問題等循環。
- `STORY_ARC`：掌握故事發展、轉折、高潮與結局。
- `CHARACTER_EVIDENCE`：用人物語言、行動、反應等證據支持人物理解。
- `TRANSFER`：把本課學到的方法遷移到新文本、生活或產出任務。
- `RETURN`：離開文本做分析後，必要時回到原句／原段驗證理解。

技能名稱是系統語言；教師端應以自然教學語言呈現。

---

## 4. Skill → Visual Tool

技能確定後，才選畫面工具。

例如：
- COMPARE → 並列、對照卡、before/after、雙場景
- INFER → 證據→推論、遮罩揭示、線索聚焦
- STRUCTURE → 流程、分支、地圖、段落骨架
- CHARACTER_EVIDENCE → 行為／語句證據卡、人物中心圖
- STORY_ARC → 故事路徑、轉折節點

禁止反向操作：

> 「這張想做時間軸，所以找內容塞進時間軸。」

---

## 5. Interaction Selection

互動也必須由理解任務決定。

可用互動語法：
- `PREDICT`：先預測
- `VERIFY`：回文本驗證
- `REVEAL`：分段揭示答案／證據
- `RETURN`：回原文確認

一頁可有兩個有層次的問題，但必須屬於同一認知場景，例如：

> 先找證據 → 再推論

而不是把兩個無關問題硬塞同頁。

---

## 6. Text Anchor Policy

所有重要閱讀教學都必須保留可追溯的 `Text Anchor`。

Text Anchor 可是：
- 課文原句
- 原段
- 關鍵詞
- 教師手冊指定文本證據

視覺化、情境化、角色對話不能取代 Text Anchor。

### RETURN 何時啟動

RETURN 不是每頁固定流程。只在下列情況啟動：
- 推論需要文本證據驗證
- 圖像可能讓學生離開原意太遠
- 比較後需要確認原文差異
- 教學目標本身是「從文本找證據」
- 教師需要把學生討論重新收回文本

若畫面已直接保留足夠 Text Anchor，且沒有理解漂移風險，不必機械再做 RETURN 頁。

---

## 7. Skill Density / Lesson Budget

技能數量由 Lesson Budget 控制。

優先序：
- MUST：本課核心理解不可缺
- SHOULD：有明顯教學價值，但可視時間調整
- COULD：延伸、挑戰、Bonus

新增技能時必須問：

> 它新增的是理解，還是只新增一個活動？

若只是形式不同但理解相同，原則上不增加技能與頁數。

---

## 8. Spiral Learning Compatibility

同一知識點可跨教材重複，但任務必須深化：

`PREVIEW → CORE_REINFORCE → RECOGNIZE → APPLY / TRANSFER`

例如形近字／多音字在預習單初遇後，正式課堂仍可用 COMPARE、RECOGNIZE、APPLY 加深；不得因「預習做過」就自動刪除。

---

## 9. Stop Rule

當下列條件成立，停止增加技能：
- 核心學習難點已被覆蓋
- MUST 已完成
- 再增加只會重複相同認知操作
- 新技能會擠壓核心文本時間
- 新技能主要服務特效／活動而非理解

---

## 10. Teacher-facing Summary

Gate A／Teaching Direction Lock 應用自然語言呈現：
- 這課最需要孩子學會什麼
- 最可能卡在哪裡
- 建議用哪些技能解決
- 哪些內容刻意不做
- Lesson Budget 大致如何分配

教師確認後，技能選擇成為 downstream invariant；若後續 Scenario、Style、Extension 需要新增技能，必須重新平衡 Lesson Budget，不得偷偷加課。
