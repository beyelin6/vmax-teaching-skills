# V-MAX Extension Layer Policy 1.0-draft

## 定位
Extension Layer 讓老師把平板、AI、跨領域、議題、主題、專題、在地文化或自訂課程掛到既有國語課核心，而不破壞 Core Engine。

> 國語課是主幹；外掛必須服務既有學習目的，或明確說明新增目的。

## Extension Types
- `DIGITAL`：平板、錄音、拍照、共編、互動作答、AI
- `CROSS`：社會、自然、藝術、數學、英語等跨領域
- `THEME`：國際、環境、品德、生命、閱讀等議題／主題
- `PROJECT`：研究、採訪、導覽、成果發表
- `REAL_WORLD`：校園、社區、家庭、在地文化
- `CUSTOM`：教師自訂／校本課程

## Modes
### LIGHT
只在最有價值的一個或少數節點融入，不重構整課。

### THEME MODE
公開課、主題課等需要時，可重新評估 Learner Role、Scenario、活動流程與成果任務，但核心文本與已確認教學目的仍受保護。

## Extension Check
每次外掛至少回答：
1. 與文本／核心技能的自然接點在哪裡？
2. 為何此工具／主題比原活動更有價值？
3. 是否需要改 Learner Role／Scenario？
4. 是否增加時間與頁數？
5. 它取代什麼？
6. 屬 CORE、PLUS 還是獨立 Extension？

若連結牽強，系統應建議降為 PLUS 或不加入，不為跨域而跨域。

## Lesson Budget Rebalance
新增 Extension 不得默認無限加頁。原則：

> 加一個活動，先問「它取代什麼？」再問「它加在哪裡？」

若確實需要新增課時，必須在 Gate A 或 Gate B 明示。

## Experience Interaction
Extension 可以影響 Experience Layer，但不得反過來讓包裝吃掉教學。例如「平板＋國際教育」可讓 Learner Role 成為小小國際導覽員，但仍須保留原課核心閱讀技能與 Text Anchor。

## Output
Extension 的成品可以是正式簡報中的活動頁，也可以是獨立平板任務／活動卡；兩者都繼承 LKB、Typography Lock、Visual Identity Lock。
