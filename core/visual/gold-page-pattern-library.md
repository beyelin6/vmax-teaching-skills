# V-MAX Gold Page Pattern Library 1.0

## 定位

Gold Page Pattern Library 位於 Visual Grammar 與 Layout / Renderer 之間，負責把「學生需要看懂的認知關係」轉譯成可執行、可檢查的學生可見頁面模式。

> Visual Grammar 回答：孩子要看懂哪一種關係？
>
> Gold Page Pattern 回答：這種關係在學生眼前應該怎麼發生？

Gold Pattern 不是固定版型、不是畫風、不是裝飾 Prompt。Theme / Style 可以改變；Pattern 的理解功能不可因 Renderer 方便而退化。

核心判準：

> Gold Page 不是「看起來很漂亮的一頁」，而是「把原本只能靠老師嘴巴講的理解，變成學生眼睛能直接看到的一頁」。

---

## 系統位置

```text
Teaching Intent
→ Director Intent
→ Visual Grammar
→ Gold Page Pattern
→ Visual Sequence
→ Layout
→ Style Recipe
→ Renderer
→ Gold Benchmark Comparison
```

不得跳過 Gold Page Pattern，直接把 Visual Grammar 翻成「左圖右文／大框＋文字／三欄卡片」。

# GP-01 WORLD_MAP｜整課圖像世界地圖

適用：全文結構、段落／詩節路徑、整課導覽、收束回顧。

核心：把課文結構變成學生能走過、回想的世界，而不是流程框。

必要特徵：
- 有一個可辨識的整課世界／空間隱喻。
- 結構節點存在於同一世界中，彼此關係可見。
- 路徑、位置、尺度或場景真的承擔文本結構。
- 角色若出現，必須活在路徑中並推動觀看。
- 5–10 秒內看得出主軸。

禁止：
- 3–6 個矩形＋箭頭冒充圖像心智地圖。
- 把段落標題貼到背景圖上，背景本身不承擔關係。
- 把全文摘要縮小塞滿一頁。

優先對應：VG-02 Moving Viewpoint、VG-08 Relationship Network、VG-09 Hierarchy & Structure。

---

# GP-02 DUAL_WORLD_COMPARE｜雙世界對照

適用：多音字、真實／想像、前後狀態、不同觀點、二元概念辨析。

核心：兩個概念不是兩欄資料，而是兩個可感知、可來回比較的語意世界。

必要特徵：
- A／B 各有具體情境或視覺證據。
- 正式比較欄位位置穩定，可快速掃視。
- 共同點／差異點可直接看見。
- 最後才以文字確認名稱、讀音、結論。

禁止：
- 左右兩欄只有文字定義，插圖只是裝飾。
- 圖片移除後完全不影響理解。

優先對應：VG-04 Comparison Field、VG-11 Figurative Transformation、VG-14 Contrast & Transformation。

---

# GP-03 SEQUENCE_DISCOVERY｜連續動作發現

適用：動作描寫、事件發展、因果、句序、需要過程才能理解的成語／意象。

核心：讓學生透過 2–4 個關鍵變化看出「怎麼發生」，而不是只看結果。

必要特徵：
- 每一格／每一鏡只推進一個清楚變化。
- 角色、場景、關鍵物件保持連續性。
- 動作路徑、姿勢、節奏或狀態改變可見。
- 幀數由理解需求決定，不為熱鬧而漫畫化。

禁止：
- 一張靜態人物圖旁邊用文字描述整個動作。
- 每個成語固定四格漫畫。

優先對應：VG-05 Motion Grammar、VG-06 Sequential Narrative、VG-07 Process & Causality。

---

# GP-04 COGNITIVE_METAPHOR｜概念具象化

適用：修辭術語、閱讀策略、寫作方法、主旨／抽象概念。

核心：不是畫「代表概念的裝飾物」，而是畫出概念運作的方式。

例如：
- 開門見山 → 真正的「一開門就看見重點」。
- 找證據 → 放大、圈選、拼合線索。
- 聯想 → 真實特徵與想像之間的可見轉化。

必要特徵：
- 視覺隱喻與認知動作一一對應。
- 學生先感受到作用，再命名術語。
- 不得讓隱喻反過來造成錯誤知識。

優先對應：VG-07、VG-08、VG-09、VG-11、VG-13。

---

# GP-05 CHARACTER_MEANING_FIELD｜字群語意辨析場

適用：形近字字群。

核心：圖像負責辨義，正式文字負責確認；一組字在同一視野中完成比較。

必要特徵：
- 至少 2 字同框比較。
- 每字包含：正式大字、注音、字義情境圖、代表例詞。
- 共同部件與差異部件位置一致、容易來回比。
- 有「哪裡像／哪裡不一樣」或等價的發現提示。
- 不因資訊完整而把字縮小或切成多頁孤立字卡。

禁止：
- 一個字一頁。
- 左圖右文字典解釋。
- 圖片只畫例詞物件卻不幫助辨義。

優先對應：VG-04 Comparison Field。

---

# GP-06 SENSORY_TRANSLATION｜感官轉譯

適用：五感描寫、情緒、飲食、童詩、寫作觀察。

核心：把無法直接投影的味道、氣味、聲音、觸感與心情，轉成可感知的視覺證據。

必要特徵：
- 可使用特寫、表情、環境反應、材質、聲音線、光影、動態等。
- 學生先感受到，再辨認感官／修辭／效果。
- 不只貼「視覺／嗅覺／味覺」標籤。

優先對應：VG-10 Sensory Focus、VG-11 Figurative Transformation。

---

# GP-07 EVIDENCE_DISCOVERY｜證據偵探

適用：閱讀理解、推論、修辭發現、聯想合理性、關鍵詞判讀。

核心：問題 → 找線索 → 聚焦證據 → 推論 → 收束，不直接把答案整理好給學生。

必要特徵：
- 原文證據必須真實存在並可辨識。
- 放大鏡、圈選、連線、局部特寫只在真的執行「找證據」時使用。
- 證據與推論在視覺上分層。
- 可保留發現空間，不預先把所有答案螢光標完。

優先對應：VG-13 Evidence Lens，可輔助 VG-04／VG-11。

---

# GP-08 CHOICE_PATH｜選擇路徑

適用：寫作選材、仿作、不同觀點、情緒選擇、開放任務。

核心：學生不是被動讀指令，而是先做一個有意義的選擇，再沿路完成任務。

必要特徵：
- 2–4 條真正不同的選擇路徑。
- 每條路徑代表不同素材、視角、情境或策略。
- 選擇會影響後續觀察／寫作／推論，不是假選項。

優先對應：VG-07 branching_choice、VG-12 Perspective & Voice。

## Pattern 選擇規則

AI 依序回答：
1. 學生第一眼應看見什麼？
2. 第二眼應發現哪個關係？
3. 圖像要承擔哪一部分理解？
4. 一張圖是否足夠？若不足，使用 Visual Sequence。
5. 哪一個 Gold Pattern 最能讓關係被直接看見？
6. 最後才選 Layout 與 Style Recipe。

每頁：
- `primary_pattern`：1 個。
- `secondary_pattern`：0–1 個；不得為豐富視覺而堆疊。

## Gold Page 共通品質 Gate

每張代表頁必須同時回答 PASS：

1. `scene_first`：第一眼有可看的場景／關係，而不是先讀說明文字。
2. `visual_evidence`：圖片承擔理解；刪掉圖會明顯損失教學功能。
3. `discovery_before_label`：需要發現的概念，不先把名稱與答案完整揭露。
4. `semantic_layout`：構圖由語意關係決定，不由模板庫決定。
5. `character_functional`：角色若出現，會改變注意、提問、策略、轉場或理解。
6. `page_surprise`：頁型與鏡頭依教學關係有變化，不連續模板複製。
7. `world_continuity`：同課世界、角色、材質、情緒與場景連續。
8. `text_integrated`：正式文字像原本就屬於畫面，不是事後貼上的大白框。

失敗分類：
- `GOLD_PATTERN_MISSING`
- `VISUAL_EVIDENCE_MISSING`
- `TEMPLATE_CARD_DRIFT`
- `LEFT_TEXT_RIGHT_IMAGE_DRIFT`
- `DISCOVERY_PREEMPTED`
- `DECORATIVE_CHARACTER_DRIFT`
- `WORLD_CONTINUITY_BREAK`
- `SEMANTIC_LAYOUT_DRIFT`

## 代表頁驗證規則

全量 Renderer 前，至少先驗證高風險代表頁：
- 一張全文／整課結構頁（若本課啟用 LVM）。
- 一張段落／課文理解頁。
- 一張語文知識比較頁（如形近字／多音字）。
- 一張句型／修辭／閱讀策略頁（若存在）。

代表頁若只是「內容正確＋排版乾淨」，但圖像未承擔理解，不得 PASS。

> 內容正確只是底線；Gold Page 必須讓孩子有東西可看、可猜、可比較、可發現。
