# V-MAX Language Knowledge Placement Policy 1.1

## 定位

本政策定義語文知識在閱讀課中的配置位置，避免所有語文項目被集中成同一種 Language Lab，也避免把應依附課文語境理解的語詞、句型與修辭抽離文本。

核心原則：

> 語詞、句型與修辭跟著課文走；字音字形系統與成語獨立處理。

其中語詞採「教師選擇重點」原則：不是教材出現的每一個語詞都要教，也不是每一個生字所組成的語詞都要另外解說。

---

## A. 跟著段落／課文走的內容

### 1. 語詞

語詞優先在原詞所在的自然段或意義段中理解，不預設抽離成課後詞語表。

但語詞教學必須經過「重點選擇」，預設不自動全教。

### 語詞選擇權

優先順序：

```text
教師指定
→ 教材／文本理解必要
→ AI 建議
→ 教師確認
```

規則：

- 教師指定的重點語詞必須處理。
- 教師未指定時，AI 可提出少量建議，但不得直接把所有語詞納入簡報。
- 一般生字所組成的語詞，不因為它是生字語詞就自動變成「重點語詞」。
- 不影響文本理解、沒有明顯語文價值、學生大多已熟悉的語詞，可只保留在來源資料，不生成解說頁。
- AI 的角色是幫老師篩選，而不是代替老師決定全部要教什麼。

AI 建議重點語詞時，可參考：

- 是否會阻礙該段理解
- 是否有特殊語境義
- 是否是作者表達的重要用詞
- 是否適合做近義／反義／搭配／語感比較
- 是否能遷移到學生口語或寫作
- 是否可能造成常見誤解

以上只是推薦依據，不是強制清單。

原因：

- 詞義常由上下文決定，離開語境容易只剩辭典式解釋。
- 學生需要理解「作者在這裡為什麼用這個詞」，而不只是知道詞義。
- 語詞可以直接連結段落畫面、人物動作、感受、事件與意象，形成較強的語意記憶。
- 語詞教學若全部展開，會稀釋真正值得學習的詞，也會破壞閱讀節奏。

建議流程：

```text
教師選定／確認重點語詞
→ 回到課文原句／原段
→ 依上下文猜義／辨義
→ 確認此處詞義
→ 看見作者用法與語感
→ 必要時做近義替換、搭配或微型遷移
→ 回到段落理解
```

若同一課被選中的多個語詞形成明顯語意網絡，可在段落教學完成後建立「詞語回望／詞語網絡」整理頁；此頁是二次整合，不取代第一次的語境理解。

### 2. 句型

句型優先放在原句所在的自然段或意義段內理解。

原因：

- 句型的功能必須結合上下文才能理解。
- 學生應先從原句發現結構，再命名形式。
- 句型教學應連結作者在該段的表達目的，而非只做形式操練。

建議流程：

```text
課文原句
→ 注意重複／排列／關聯
→ 發現句型結構
→ 命名
→ 說明在本段的表達效果
→ 必要時立即微型遷移
```

不得預設把所有句型統一移到課後集中頁。

### 3. 修辭

修辭優先依附其原始段落與語境處理。

原因：

- 修辭的重點不是只辨認名稱，而是理解作者為何在這裡這樣寫。
- 譬喻、擬人、排比、誇飾等效果通常與該段意象、情緒、節奏或觀看方式直接相關。
- 抽離語境容易退化成「找修辭名稱」的題型訓練。

建議流程：

```text
原句／原段
→ 看見真實內容
→ 看見作者的語言轉化
→ 感受效果
→ 命名修辭
→ 回到段落理解
```

Visual Grammar 可依內容選用 Figurative Transformation、Contrast、Sequential Narrative、Sensory Focus 等語法。

## B. 原則上獨立處理的內容

以下項目建立獨立 Knowledge Lab / Language Lab：

- 生字
- 形近字
- 多音字
- 成語

獨立不是指彼此隔離，而是脫離段落逐頁循環，改以「知識關係」組織。

### 生字

依來源教材完整收錄，但「完整收錄」不等於「每字都要同樣深教」。

可依教師需求與教材重點分組。不得強制一字一頁，也不得因為每個生字都有教材語詞，就自動替每個生字語詞建立解說。

生字的正式字音、字形、部件、形近關係與必要辨析放在獨立區塊；若某生字所在語詞被教師選為重點語詞，則在段落語境中處理該語詞。

### 形近字

同一比較關係盡量同場呈現，建立 Comparison Field。

### 多音字

用「讀音 × 語意 × 情境」比較，不只是列音表。

### 成語

成語原則上獨立處理，因為通常需要完整語義、情境、近反義、誤用辨析或遷移。

Visual Grammar 依語意決定：單一情境、前後對照、四格／多格 Sequence、誤用辨析等。不強制一成語一模板。

如果成語本身直接出現在課文且是理解當段不可缺少的內容，段落中先依上下文處理「此處意思」；完整成語學習仍留在獨立區塊。

## C. Just-in-Time Exception｜段落即時點亮例外

若某個生字讀音、形近辨識、多音字讀音或成語是理解當前段落不可缺少的關鍵，允許在段落內先做「即時點亮」。

段落內只處理足夠閱讀所需的最小資訊，例如：

- 此處的讀音
- 此處必要的字形辨識
- 成語在本段的語境義

完整知識仍回到獨立 Knowledge Lab 處理，例如：

- 完整形近字比較
- 多音字其他讀音與語意
- 成語完整語義／情境／遷移

注意：一般語詞不屬於「例外點亮」，因為被教師選定的重點語詞本來就屬於段落閱讀的一部分；未被選定的語詞也不應因 AI 覺得「可以教」就自動展開。

## D. Director Engine 配置規則

Director Engine 安排 Learning Acts 時：

1. 先依自然段／意義段建立閱讀 Acts。
2. 讀取教師已選定的重點語詞；若教師未指定，可提出精簡候選清單供確認。
3. 只在各 Act 中標記「已選定／已確認」的重點語詞，以及該段應處理的句型與修辭。
4. 不得把所有教材語詞、生字語詞或可查到的詞義自動生成為教學內容。
5. 標記必要的 Just-in-Time 字音字形／成語支援。
6. 閱讀主體完成後，再建立獨立 Knowledge Lab，整理生字、形近字、多音字與成語。
7. 若已選重點語詞之間有值得回望的語意關係，可新增「詞語網絡／詞語回望」整合頁。
8. Knowledge Lab 的順序與數量由內容關係決定，不設固定頁數。
9. 不得使用「每段內容頁 → 生字頁 → 修辭頁 → 問題頁」的固定循環。

---

## E. 教師確認點

在正式產出簡報前，若教師尚未指定語詞重點，系統只需要提供少量候選，而不是整份詞語清單逐項詢問。

建議互動形式：

```text
本課建議深教語詞：A、B、C、D
A｜全部採用
B｜我自己選
C｜不特別教語詞
```

教師可直接增刪；最終選擇權屬於教師。

## F. 教學節奏

推薦的概念順序是：

```text
閱讀段落
→ 在原文裡處理教師選定的重點語詞
→ 在原文裡發現句型／修辭
→ 完成段落與全文理解
→ Knowledge Lab 建立字音字形與成語關係
→ 必要時回望已選重點語詞網絡
→ 遷移／練習／創作
```

但若教師另有教學意圖，可前置或穿插 Knowledge Lab；Teacher Intent 永遠優先。

## F.1 課文小節施工節奏

對詩歌、短文或自然段明確的課文，簡報施工預設以小節／自然段為單位：

```text
課文＋詞語
→ 語文特色（句型／修辭／類疊／節奏／寫法）
→ 文意深究
```

這是閱讀理解的順序，不是固定三頁模板。若某小節沒有值得獨立處理的語文特色或深究，可省略；若需要更充分討論，深究可加頁。不得在同一頁同時完成三個階段。

---

## G. 核心檢核

生成簡報或教材前檢查：

- 重點語詞是否由教師選定，或至少經教師確認？
- 是否錯把「每個生字語詞」都當成必教語詞？
- 未選語詞是否仍保留在來源資料，而沒有被無故刪除？
- 被選語詞是否回到原句與上下文理解，而不是只給辭典義？
- 句型是否保留課文原句與語境？
- 修辭是否說明表達效果，而非只貼名稱？
- 生字與形近字是否建立可比較關係，而非逐字拆頁？
- 多音字是否呈現語意情境？
- 成語是否依語意選擇適合的情境／Sequence，而非固定模板？
- Knowledge Lab 是否成為真正的語言工具區，而非課文之外的附錄？

---

## 核心金句

> 語詞要跟著課文，但重點要由老師決定；AI 的工作不是把每個詞都講完，而是幫老師把真正值得教的詞看得更清楚。
