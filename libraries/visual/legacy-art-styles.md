# V-MAX Legacy Art Style Library

> 來源：Omni Architect `visual-library.ts`
> 狀態：Bee Original／保留，但重新分層

舊系統把畫風、世界觀與資訊設計語言放在同一層。新版需拆成 Art Style、Theme World、UI Language 三層，避免概念混用。

## A. Art Style｜畫面材質與表現

- 清新水彩：柔和水彩、紙張質感、低刺激色彩
- 精緻剪紙：多層紙雕、景深、手作立體感
- 新國風水墨：水墨筆觸、留白、東方美學
- 3D 軟陶：圓潤、柔軟、玩具感
- 像素積木／可愛像素：遊戲感、模組化
- 塗鴉手帳：手繪筆記、格紙、學習歷程感
- 奇幻繪本：故事書、混合媒材、童話氛圍
- 療癒色鉛筆：溫暖、紙纖維、細緻手繪
- 復古浮世繪：平面構圖、裝飾性線條
- 黑白漫畫：網點、墨線、敘事張力
- 波普藝術：高對比、漫畫視覺語言
- 低多邊形：幾何切面、現代 3D 感

## B. Theme World｜世界觀與敘事包裝

- 溫暖動畫／自然故事世界
- 科幻藍圖
- 賽博龐克
- 蒸氣龐克
- Vtuber 學院
- 熱血少年任務
- 暗黑哥德謎題
- 奇幻魔法世界

> Theme World 不等於畫風。例如「自然探險」可以用水彩，也可以用剪紙。

## C. UI Language｜資訊介面語言

- 現代扁平
- 幾何資訊圖
- 科技 HUD／藍圖介面
- 漫畫分鏡
- 手帳卡片
- 任務徽章／木牌／地圖標籤

# 新版選擇規則

不要問「選哪一個風格代碼？」而應拆成三步：

```yaml
visual_profile:
  art_style: watercolor
  theme_world: nature_explorer
  ui_language: field_journal
```

AI 可以推薦 2–3 組組合並說明理由，最終由教師選擇。

## 選擇依據

- 課文情緒
- 文體與主題
- 學生年段／Learning Profile
- 圖像是否需要真實資訊辨識
- 是否需要角色敘事
- NotebookLM / 圖片式簡報的渲染穩定度
- 是否與本課全文 Structure 相容

## 禁止事項

- 不因追求風格而犧牲教材可讀性
- 不使用過度高刺激配色造成閱讀負擔
- 不把同一套課程每頁換不同畫風
- 不以畫風名稱直接決定角色或版型
- 不把 Theme 當作裝飾；世界觀必須服務 Lesson Flow
