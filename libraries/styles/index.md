# V-MAX Style Library Index

## 定位

Style Library 保存可重用的視覺 DNA，不保存特定課次的教材內容。每次使用都必須依當課教材重新建立場景、插圖、章節名稱與版面組合。

## 目前核心風格

### STYLE-WA-001 水彩探險手冊

- 適合：自然觀察、記敘文、探索主題、成長故事
- 視覺：水彩筆觸、米白紙張、手繪邊框、木牌或徽章標籤
- 配色：藍綠自然色、木質褐色、柔和橘黃
- 注意：童詩需增加留白；說明文需降低裝飾並強化圖解

### STYLE-WH-002 溫暖手繪動畫

- 適合：生活故事、童詩、人物情感、低中年級教材
- 視覺：柔和線條、溫暖場景、適度動畫感、友善表情
- 配色：奶油色、珊瑚橘、柔和藍綠、暖棕
- 注意：避免過度幼兒化；中高年級需提高資訊結構感

### STYLE-JP-003 日系手繪繪本

- 適合：童詩、生活觀察、自然景物、情感書寫
- 視覺：色鉛筆或淡彩、自然留白、小型情境插畫
- 配色：低飽和自然色、米白、淡綠、淡藍、暖黃
- 注意：資訊密集頁需搭配清楚圖卡與欄位

### STYLE-KW-004 韓漫校園敘事

- 適合：法律教育、品格、人際互動、校園案例、高年級議題
- 視覺：漫畫分鏡、情緒特寫、對話框、速度線與場景切換
- 配色：依主題調整，常用冷灰、藍、黃或暖紅作重點
- 注意：不得將嚴肅議題娛樂化；避免畫面過度戲劇化

### STYLE-IG-005 清楚資訊圖解

- 適合：說明文、語文規則、比較辨析、流程、結構與評量
- 視覺：資訊卡、箭頭、比較表、圖示、流程圖
- 配色：高辨識但低干擾，章節色彩明確
- 注意：避免整套簡報只有圖表，仍須保留情境與閱讀節奏

### STYLE-BX-006 便當盒教學圖卡

- 適合：A4 學習單、班級宣導、重點整理、中年級閱讀材料
- 視覺：分格區塊、圓角圖卡、日系手繪小插圖、清楚分類
- 配色：溫暖柔和、區塊分色、白底或米白底
- 注意：單頁區塊不可過碎，文字與插圖必須放大並保持協調

## 使用方式

Style Recommender 必須從本索引選擇候選風格，或提出新增風格需求。推薦時不能只回傳名稱，必須依當課內容說明：

- 為何適合
- 如何調整成該課專屬版本
- 與角色如何協調
- 適用哪些投影片
- 有何風險或限制

## 後續擴充格式

每個正式風格資料夾建議包含：

```text
libraries/styles/{style-slug}/
├── style.md
├── palette.md
├── illustration-rules.md
├── layout-mapping.md
└── examples.md
```
