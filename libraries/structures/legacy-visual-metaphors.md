# V-MAX Legacy Visual Metaphor Library

> 來源：Omni Architect `visual-library.ts`
> 狀態：Bee Original／保留並升級

這些不是裝飾模板，而是「用視覺形狀協助學生理解內容結構」的思考工具。

## M1｜冒險地圖
- 原始視覺：羊皮紙、虛線、羅盤
- 適合：旅程、探索、事件順序、任務式課文
- 理解功能：看見路徑與前後關係
- 避免：非線性概念硬套成旅程

## M2｜生態解構圖
- 原始視覺：放大鏡、標籤、中心放射
- 適合：自然、科普、構造、特色、功能
- 理解功能：從整體拆解局部
- 避免：純敘事課文

## M7｜漫步小徑
- 原始視覺：蜿蜒小路、時間軸、小場景節點
- 適合：生活記敘、旅行、成長過程
- 理解功能：依時間或經歷逐步前進

## M3｜故事絲帶
- 原始視覺：緞帶、節點、柔和路徑
- 適合：情感流動、童話、較柔性的事件發展
- 理解功能：看見故事／情緒的連續變化

## M4｜情緒溫度計
- 原始視覺：刻度、天氣圖示、起伏
- 適合：人物情緒、態度轉折、情感變化
- 理解功能：把抽象情緒轉成可觀察變化

## M5｜雙軌對照圖
- 原始視覺：左右分割、雙路線
- 適合：比較、兩種觀點、前後差異、人物對照
- 理解功能：建立異同比較

## M6｜運鏡膠捲
- 原始視覺：膠捲、分鏡、視角切換
- 適合：事件片段、畫面描寫、鏡頭感、動作場景
- 理解功能：把文字轉成連續畫面

## S1｜五感雷達圖
- 原始視覺：雷達圖、感官標籤
- 適合：寫景、觀察、描寫、寫作準備
- 理解功能：整理視覺／聽覺／嗅覺／味覺／觸覺

## S2｜想像力氣球
- 原始視覺：氣球、漂浮、連結
- 適合：童詩、聯想、想像、創意寫作
- 理解功能：由實際事物向外延伸聯想

## S3｜時光列車
- 原始視覺：車廂、橫向連結
- 適合：時間順序、生平、歷史、成長
- 理解功能：清楚標示時序與階段

## S4｜觀點天平
- 原始視覺：天平、平衡、對比
- 適合：論說、價值判斷、雙方觀點、優缺點
- 理解功能：比較證據與立場

## S5｜奧利奧圖
- 原始視覺：夾心餅乾、層次
- 適合：段落結構、夾心式論述、主題句＋細節＋收束
- 理解功能：看見上下層與核心層

## S6｜漢堡圖
- 原始視覺：漢堡、層次
- 適合：段落寫作、主題句＋支持細節＋結尾句
- 理解功能：建立段落鷹架

## S7｜Q版博士腳本
- 原始視覺：分鏡格、狀聲詞、角色、畫面／音效／台詞
- 適合：科普、影音腳本、角色主持、數位創作
- 理解功能：將知識轉成多模態敘事

---

# 使用規則

1. 先判斷「學生需要理解什麼」，再選視覺隱喻。
2. 文體只提供推薦，不作硬性綁定。
3. 同一 Structure 可套不同 Theme。
4. 不適合的結構寧可不用，不為了好看強行套版。
5. 全文導航、段落副架構與寫作架構可使用不同隱喻。

## 推薦輸出格式

```yaml
structure_recommendation:
  primary:
    code: M7
    reason: "事件依時間前進，學生需要掌握經歷順序"
  alternatives:
    - code: M3
      reason: "若教學重點轉向情緒變化，可改用故事絲帶"
  teacher_choice_required: true
```
