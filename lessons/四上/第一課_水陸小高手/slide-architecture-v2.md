# 第一課《水陸小高手》V2｜Slide Architecture

> 狀態：教學架構版，尚未進入正式 Renderer。
> 目標：把已確認的 Director Map、Knowledge Lab、Comparison Field、成語 Visual Sequence、Text/UI 與 Image-first Hybrid Renderer 整合成一條完整的課堂觀看路徑。

## 一、總體設計

- 文體：童詩，由〈游泳〉與〈溜直排輪〉兩首詩組成。
- 核心觀看路徑：**真實動作 → 感官線索 → 聯想畫面 → 詩句節奏 → 內在感受 → 遷移創作**。
- 課文六個自然段本身具有完整意義功能，本課採「自然段 ≈ 意義段 ≈ Reading Act」；不為固定幕數重新切割。
- 預估正式簡報：**35 頁左右**。頁數是理解結果，不是硬上限；正式渲染前可依代表頁測試合併 ±2 頁。
- 不使用舊版「內容頁 → Bee 對話頁 → 挑戰頁」三頁循環。
- Bee／小樂只在觀看路徑需要被點醒、轉場或反思時出現；大多數頁面由文本與畫面自己說話。
- 文字策略：詩句、注音、生字、多音字、成語定義、例句、正式題目採 Hybrid 精準文字層；主場景與整體構圖採 Image-first。

## 二、全課 35 頁架構

### ACT 0｜進入水陸世界（P1–P3）

#### P1｜封面：水陸小高手
- 功能：ENTER / immerse
- 第一視線：水中游泳與陸上直排輪形成同一個世界的雙場景。
- 學生文字：課名＋極短引題。
- 角色：OFF。
- Renderer：Image-first；標題可 Hybrid overlay。

#### P2｜身體先進入詩裡
- 功能：ENTER / connect
- 問題：運動時，你的身體會怎麼動？你曾覺得自己像什麼？
- 視覺：魚、蛙、蝶、飛鷹、陀螺只作若隱若現的預告，不揭示完整答案。
- 角色：小樂可作 student proxy，一句即可。

#### P3｜兩首童詩，六個畫面
- 功能：structure / navigation
- 水中三站：魚蛙蝶 → 笑聲水珠 → 自信壯志。
- 陸上三站：飛鷹 → 陀螺 → 煩惱與快樂。
- 視覺語法：Hierarchy & Structure / dual-track journey。
- 角色：Bee 可用一句導航，不佔主視線。

### ACT 1｜〈游泳〉：身體變成想像（P4–P10）

#### P4｜〈游泳〉完整閱讀
- 功能：read / feel rhythm
- 保留原詩三段、行分、留白與節奏。
- 不在此頁插入分析標籤。
- Renderer：Hybrid 精準文字層＋沉浸水中場景。

#### P5｜先看動作：游泳時身體像什麼？
- 功能：NOTICE
- 不先給魚／蛙／蝶答案；先讓學生看三種游泳動勢或姿態。
- 問題：哪一種動作讓你想到哪種生物？
- 視覺語法：Motion Grammar / delayed reveal。

#### P6｜游成魚、蛙、蝶
- 功能：DISCOVER / compare
- 核心：同一個「游」如何依特徵長出三種聯想。
- 正式原句保留「游成……」重複結構。
- 視覺語法：Comparison Field + Figurative Transformation。
- 角色：OFF。

#### P7｜笑聲怎麼變成水珠？
- 功能：DISCOVER / sensory transformation
- 呈現「歡樂笑聲一陣陣 ↔ 晶亮水珠一串串」的互換關係。
- 不是泳池快樂插圖，而是讓聲音與水珠在畫面中互相轉化。
- Bee 可在 reveal 後一句點醒：「看不見的聲音，也能被寫成看得見的畫面。」

#### P8｜游出去的，不只有泳姿
- 功能：REVEAL / deepen
- 從身體進到內在：自信 → 壯志 → 多采多姿的人生。
- 視覺由泳池近景逐步拉向更開闊的海與人生道路，形成情緒擴張。
- 原句精準呈現「游出……」結構。

#### P9｜「一般」到底是哪一種意思？
- 功能：language-in-context
- 第一欄：大海一般的壯志＝同樣、同等／像……一樣。
- 第二欄：一般人、表現一般＝普通、通常。
- 視覺語法：Comparison Field；同欄位對齊語境、意思、例句。
- 不脫離 Act 3 原句教多義詞。

#### P10｜〈游泳〉三段其實在往哪裡走？
- 功能：PAUSE / synthesize
- 三層：身體聯想 → 歡樂感官 → 內在自信與展望。
- 不做「段落大意卡片牆」，而做水面向外擴散的三層意義波紋。
- 角色：OFF。

---

### ACT 2｜〈溜直排輪〉：速度、旋轉與心情（P11–P16）

#### P11｜〈溜直排輪〉完整閱讀
- 功能：read / feel rhythm
- 保留原詩三段與短句節奏。
- Renderer：Hybrid 精準文字層＋風與速度的沉浸場景。

#### P12｜先別看飛鷹：你看到了哪些真實線索？
- 功能：NOTICE / evidence
- 線索：風從耳旁吹過、景物快速消失、滑行加速。
- 問題：這種感覺像什麼？
- reveal_policy：delayed。

#### P13｜為什麼是飛鷹？
- 功能：DISCOVER / infer
- 左：真實滑行；右：飛鷹遨遊；中：速度、風、自由三條證據連線。
- 視覺語法：Evidence Lens + Figurative Transformation。
- 小樂可提問；Bee 不直接講答案。

#### P14｜轉身跳躍，跳躍轉身
- 功能：sequence / rhythm
- 用 3–4 格連續動作顯示轉身、跳躍、旋轉的節奏。
- 最後才出現陀螺意象。
- 視覺語法：Sequential Narrative + Motion Grammar。

#### P15｜為什麼是陀螺？
- 功能：DISCOVER / compare
- 比較「人的轉身跳躍」與「陀螺旋轉」共同特徵。
- 「美麗如虹」作為結果意象，不與動作比較搶主視線。
- 金句可保留：聯想不是亂想，是抓住最像的特徵。

#### P16｜風吹走了什麼？留下了什麼？
- 功能：PAUSE / reflect
- 左側煩惱被風帶走，右側快樂緊緊跟隨；整體節奏慢下來。
- 原詩「緊緊的、緊緊的」保留重複感。
- 角色：OFF 或小樂一句個人連結。

### ACT 3｜兩首詩共用的寫作祕密（P17）

#### P17｜原來兩首詩都用了同一把鑰匙
- 功能：REVEAL / transfer
- 核心流程：真實動作 → 抓住特徵 → 長出聯想 → 形成節奏 → 寫出感受。
- 左以游泳證據，右以直排輪證據，中間用共同流程串聯。
- 這頁才正式命名「聯想／類疊」等寫法；先發現後告知。

### ACT 4｜Knowledge Lab：字形、字音、部件（P18–P26）

#### P18｜15 個生字總覽：先認路，不一次深究
- 功能：overview
- 教材生字完整保留：泳、串、般、姿、耳、鷹、滑、遨、緩、陀、螺、轉、躍、煩、溜。
- 只做總覽與必要辨識，不在一頁塞滿所有筆順、部首、成語。
- 教師選定的深教字群才進後續 Comparison Field。

#### P19｜CF1：泳／永／詠
- 完整比較場。
- 共同核心與水／言部件連回意義與例詞。

#### P20｜CF2：溜／留／遛
- 完整比較場。
- 「溜直排輪」與生活語境連結。

#### P21｜CF3：遨／熬／傲 ＋ 緩／暖／援
- 兩個小型比較場同頁，採 progressive reveal。
- 不同字群有清楚視覺分區，不混成六張卡。

#### P22｜CF4：螺／騾／累
- 把「累」同時當作字與共同構件來看。
- 視覺呈現字形關係，而非只靠顏色標部件。

#### P23｜CF5：姿／資 ＋ 躍／耀
- 兩個雙字比較場。
- 同欄位對齊：字形、部件、例詞、圖像語意。

#### P24｜CF6：鷹／應 ＋ 陀／駝／坨
- 快速辨析頁。
- 「坨」明確標記為教師補充；來源 provenance 不消失。
- 不把短辨析擴張成重課。

#### P25｜多音字：溜
- 兩個語境同場：溜走／溜直排輪。
- 讀音綁定動作與語境，不做孤立音表。
- 注音採精準文字層。

#### P26｜多音字：轉 ＋ 部件小實驗「耳／女」
- 上半：轉身／轉圈以動作差異辨讀音。
- 下半：耳、女變成偏旁時的位置與字形變化，以「部件變形實驗桌」快速呈現。
- 若代表頁測試顯示過載，可正式渲染時拆成 P26–P27；此為唯一預留的 +1 頁彈性點。

### ACT 5｜成語生活應用（P27–P31）

> 原則：5 個成語 ≈ 5 頁。每頁至少保留「圖像理解＋正式/學生可懂意思＋生活例句」，不為省頁把多個成語擠在同頁。

#### P27｜躍躍欲試
- Visual Sequence：看見挑戰 → 很想試 → 準備行動。
- 生活例句：看到大家在玩直排輪，我也躍躍欲試。
- 核心辨義：很想試，但重點在「還沒真正開始」的期待狀態。

#### P28｜心煩意亂
- 前後情境對照：事情纏在心裡、思緒混亂。
- 生活例句＋連回「煩惱被風帶走」。

#### P29｜耳目一新
- Before / After。
- 生活例句：教室重新布置後，讓大家覺得耳目一新。
- 避免把成語畫成字面上的換耳換眼。

#### P30｜洗耳恭聽
- 單一完整生活情境即可。
- 生活例句放在畫面構圖中，但採正式文字層。

#### P31｜回心轉意
- 3 格：原本決定 → 發生理由／受到勸說 → 改變心意。
- 生活例句必須能看出「原先想法」與「後來改變」。

### ACT 6｜從閱讀走向自己的童詩（P32–P35）

#### P32｜〈放風箏〉：另一首詩怎麼把畫面寫出來？
- 功能：TRANSFER / model
- 保留教材原有欣賞活動：找景物詞語、想像畫面。
- 不把〈放風箏〉講成新的完整課文；它是第二個寫作示例。

#### P33｜拆開看看：一首有畫面的童詩怎麼長出來？
- 功能：writing scaffold
- 從本課與〈放風箏〉共同抽出可遷移流程：
  1. 我真的在做什麼？
  2. 哪個動作／感覺最明顯？
  3. 它讓我想到什麼？
  4. 哪一句可以重複形成節奏？
  5. 最後我想留下什麼感受？
- 支架是選項，不是固定填空模板。

#### P34｜換你寫：我是＿＿小高手
- 功能：CREATE
- 學生可選自己的運動／活動。
- 畫面保留大量作答／口說空間；少裝飾。
- 可提供 2–3 個開句支架，但不強迫使用。

#### P35｜回頭看：你現在會怎麼看一首童詩？
- 功能：REFLECT / assess / close
- 無答案任務：給一個新活動畫面，讓學生說出「真實線索 → 聯想 → 感受」；或回答「你運動的時候，覺得自己像什麼？為什麼？」
- 最後回扣課名與學習旅程。
- 角色：Bee／小樂可一起收尾，但不講長篇金句。

## 四、角色出場控制

預設角色 OFF。建議只在下列功能點出現：
- P2：小樂作學生代理，開啟生活連結。
- P3：Bee 一句導航。
- P7：Bee 在學生發現後點醒感官轉換。
- P13：小樂提出「為什麼是飛鷹？」。
- P16：小樂作情感連結（可選）。
- P17：Bee 可做一次短 Reveal。
- P35：Bee＋小樂收尾。

目標：35 頁中角色明顯出場約 5–7 頁，不為存在而存在。

## 五、Renderer 分流

### Image-first 優先
P1、P2、P3、P5、P7、P8、P10、P12–P17、P27–P35 的主視覺。

### Hybrid 精準文字層優先
P4、P6、P8–P9、P11、P14–P18、P19–P26、P27–P31 的成語名稱／定義／例句，以及所有正式問題。

### 高精準 analytic
P18–P26：生字、字群、多音字、部件。

原則：**不要因為需要正確文字，就犧牲整體構圖；也不要因為整頁圖片漂亮，就允許核心教學文字錯誤。**

## 六、正式渲染前代表頁測試

先製作 8 張代表頁，不直接全做：
1. P1 封面
2. P3 全文導航
3. P6 游成魚／蛙／蝶
4. P7 笑聲 ↔ 水珠
5. P13 飛鷹證據推理
6. P14 陀螺動作分鏡
7. P22 螺／騾／累 Comparison Field
8. P27 躍躍欲試成語頁

代表頁需通過 Quality Gate：
- 觀看路徑清楚
- 圖像承擔理解功能
- 正式文字正確
- Hybrid 文字與圖片像同一張設計，不像後貼上去
- 角色自然且必要
- 與舊版並排時，教學清楚度、畫面記憶、節奏、角色自然度至少三項提升

通過後才展開完整 35 頁。
